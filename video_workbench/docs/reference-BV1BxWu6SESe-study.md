调研日期：2026-11-12。用户要求研究参考视频有哪些值得吸取的优点；本次只调研，没有复制作者素材或动画源码，没有创建付费实验、修改运行服务或部署。OpenSpec 由主 Agent 统一同步。

参考：[等二月花开《久等了！Fable 5.2 纯代码炫技短片〈万物〉| 狂烧16亿Token》](https://www.bilibili.com/video/BV1BxWu6SESe/)。

## 结论

最有价值的是让波、流体、粒子和空间本身成为画面主体，再用材质、明暗和镜头建立层次。它提供了比常见框图更广的视觉语言，适合作为现有动画实验室的参考目标。当前 video-service 已有 SVG/HTML、Canvas 2D 和 Three.js，不必为了研究这些机制先增加引擎或拆出新服务。

但这是一条跨题材的视觉短片，不是可以直接照搬的技术解说流程。我方应学习其美术和空间组织，把效果落实为可读的因果、持续可追踪的对象和服务解释的镜头，避免只增加粒子、泛光与运镜。参考视频的完整转场、运动质量和音画关系，本轮证据不足以作出结论。

## 与现有服务的差距

已读取当前代码：`animation_runtime_capabilities.py` 接纳 `html-svg`、`canvas`、`three`；正式创作合同为1280×720、24fps；运行时固定 Three.js r170 WebGL2，以 SwiftShader 软件渲染，方法合同不允许任意引入 addons 或外部资源。

因此首要差距是创作目标和验证方法，而不是缺少 Canvas／Three.js 名字。现有运行时可以承载相关研究方向；它没有因此自动具备成熟的流体、体积渲染或重型 raymarching 管线。尤其复杂 shader、大量透明叠加和高密度粒子需要单独实测渲染时间与失败边界。应先在现有720p合同下验证表达，再决定是否扩展运行时。

实验成果应包含可复现的创作要求、成功与失败条件、确切方法版本和代表样片，使通用 Agent 能迁移生成；不应由工程师手写固定动画模板来冒充能力改善。

## 建议进入效果库的五个目标

这些是候选实验，不代表已经创建或验收。每项先做一个完整表达片段，再用不同对象或语境验证迁移，避免只给同一个模板换文字。

| 优先级与目标 | 对应参考及现状差距 | 给 Agent 的创作目标 | 验收重点 |
| --- | --- | --- | --- |
| P1 有解释作用的场与干涉 | 双波源；我方已有波场方向，但需要提升层次和解释性 | 用两种来源、可追踪观察点与局部增强／抵消，展示一个清楚的因果变化；Canvas优先 | 固定参照下源、波前和变化关系正确；关键区域醒目；改变源参数后仍能读懂；细线经最终MP4编码后清晰 |
| P1 程序化材质与氛围 | 水墨远山、水面、红金卷涡；单一扁平填色表现范围有限 | 围绕一个主体，让表面纹理、边缘、环境响应和景深层次共同表达材质；不套统一滤镜 | 同一对象材质连续；前中后景可分；纹理不过度闪烁；材质增强理解，不遮住关键动作；保留可控渲染成本 |
| P2 有空间参照的镜头 | 城市局部与全景、星系盘；空间效果不能只靠旋转主体 | 在同一世界从局部到整体，使用遮挡和视差保持位置关系；Three.js适用 | 主体身份与空间关系持续可追踪；镜头进入、停留、退出有目的；没有穿模、眩晕或因转向丢失焦点；逐帧寻址可复现 |
| P2 高密度粒子与结构层级 | 星系、彩色网球；密度增加容易变成视觉噪声 | 让粒子形成可辨认结构，以核心、外围、前后景与颜色编码表达组织和流向 | 关键对象在高密度下可追踪；明暗分级明确；透明度和颜色没有淹没主体；粒子、透明叠加及shader成本经实测 |
| P2 同一主题中的风格变化与衔接 | 原片跨波场、水面、粒子和空间题材；实际转场尚未验证 | 以共同对象或不变量连接两种视觉表达，例如同一波前进入水面、同一群体由散点形成结构 | 转换前后“还是同一对象”可被观众识别；过渡承担逻辑而非填充；段间节奏统一，尾部能收束。这是我方目标，不声称原片已这样完成 |

每次实验先冻结质量标准和资源预算，让 Agent 制作、检查并比较完整样片；无明显改进可提前结束，保留最佳结果和未解决问题。开发者实验可以继续新委托，不套用正片默认一轮、用户主动最多再两轮的打磨限制；也不因此获得无预算无限重试授权。

## 声音和成本的取舍

本片的声音本轮未核实，暂时不能给出可证实的“他的配音／音效优点”。我方无旁白实验仍可使用有意义的音效，是否采用应在实际试听中判断；正式视频继续沿用项目统一音色和声音时钟，让旁白、动作和停留共同服务理解，无需改用标题中的模型或特定语音引擎。

111秒、4K资源和作者高消耗自述，不应转化为我方的质量门槛或复制成本方案。最合适的第一步是在现有合同下验证“场与干涉”和“材质氛围”两个小目标，分别观察表达收益和实际渲染成本，再推进空间镜头及高密度效果。研究期间不扩展多图层编辑器，不拆公共渲染服务，也不新增无边界的自动打磨。
