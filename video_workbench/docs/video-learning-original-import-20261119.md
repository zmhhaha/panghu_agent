## 受控维护导入

使用维护命令 `python -B -m video_workbench.video_learning_import`，不增加公开上传或绕过渲染的业务 API。

导入包保存源代码、原学习输入与绑定、原始和派生宿主、派生渲染请求、运行计划、停止回执、媒体及逐文件 SHA。维护入口回查原项目、候选、操作和冻结输入，核对源码、宿主、请求、媒体以及资源来源，实际探测、解码和抽帧。

导入产生独立实验、候选和可追溯导入事件，保留原失败实验和 ledger，不伪造新的 Agent 评分、迁移验证或连续听审结论。相同请求幂等，不重复增加作品。导入本身不更改内部最佳或默认作品，默认采用通过现有采用接口完成。

实际资源范围仍是已批准的本次离线配置：4 CPU、3 GiB、180 秒单帧时限；生产默认限制不随导入改变。以后增加资源仍须得到开发者允许。
