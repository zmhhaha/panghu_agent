# 效果库看片与反馈（2026-11-11）

本轮先补齐开发者看片、比较和提出具体意见的界面。真实 Agent 创作、
新角色运行准入与激活继续暂停；这里的界面能力不代表生成链路已经启用。
前端按本轮开发分支交付；独立生成后端仍未启用。

## 当前入口与保留边界

正式开发者入口使用 methods-only 模式，以完整效果片段和关联方法为主。
旧的固定样例、组件参数回归、旧标注页及其旧 API／静态入口关闭；
该模式不加载旧样例，也不创建旧标注和实验数据库。

已有回归实现与测试保留给内部维护，继续验证基础媒体、渲染、定位和隔离行为。
它们不作为新版效果库菜单，不迁入旧测试作品或历史意见，也不限定 Agent 的创作方式。
本轮不清理服务器历史数据。

## 本轮界面验收范围

- 可以从历史候选任意选择左右版本，也可以只观看一个版本。
- 提供共享时间位置、播放／暂停、归零、24fps 时间步进、拖动和倍速控制；
  片长不同的候选到末尾后保持末帧。
- 音效选择只播放左侧、右侧或静音，避免两份音效叠在一起。
- 对具体版本填写文字意见和问题时间段；比较结果可选左侧、
  右侧、相当或都不满意，已保存意见可以撤回并保留记录。
- 实际媒体和源码通过受控接口下载。没有实际媒体时，播放控制禁用；
  页面布局示意只演示控件，不伪装成已经生成或认可的样片。
- 继续优化时，所选版本未撤回的文字意见及时间范围带入可编辑表单，
  由开发者核对后显式提交。偏好只作比较记录，不自动更换最佳版本。

画面区域校验已在反馈接口中准备，本轮没有新增区域框选界面。

同步控制使用视频的原始秒数。不同剪辑尚未进行语义时间对齐；
共享时间控制也不等于浏览器已经实现两个 MP4 解码画面的严格逐帧锁定。
实际观看和试听由开发者完成，控制器状态不自动产生视听确认或发布许可。

## 构建与运行状态

`method-comparison.mjs` 作为明确列出的前端源码进入离线构建上下文和 Docker
允许清单，并由 methods-only 静态路由交付。构建回归核对实际模块字节，
缺失模块时在生成上下文前失败；运行数据、临时结果和凭据不进入上下文。

本轮验证不调用模型、不运行真实渲染，也不启用新角色。后端不可用时，
页面应明确显示状态并禁用实际提交、意见保存、迁移和发布操作。
真实生成、样片与迁移的认可、方法发布和正式制作应用仍需各自验收。

## 本轮验证

- Python 反馈持久化、服务、真实两跳 HTTP 与构建交付联合检查：147 项通过。
- 前端控制器、比较播放器、反馈绑定与预览边界：45 项通过。
- 本地浏览器使用明确标注的技术夹具和两条已有 8 秒 MP4，验证同步播放、暂停、
  逐帧、0.5 倍速、单侧音效、切换版本、历史意见跳到 2 秒、意见保存后清空、
  撤回保留原记录、未撤回文字意见进入可编辑优化表单，以及新建提交后的详情切换。
- 浏览器发现的重复 canplay 引发重复 seek 已修复，并增加回归。
- 测试夹具只使用本地内存，未迁入线上效果库，未调用模型或真实生成任务。
