## 实际闭环与证据

实验冻结预算为两轮、1,200 秒，全部角色禁用 WikiSkill。总计 **10 个操作：7 个 Agent 作业与 3 次真实渲染**；Agent 作业为 3 次创作、3 次独立评审、1 次迁移任务设计。这里的 7 是作业数，不是模型请求数，本次没有汇总模型请求数量。

首轮作者收到原始参考图；首轮评审收到参考图和实际渲染结果。第二轮作者收到参考图与真实首图，第二轮评审同时看到参考、当前图和基线。七个 Agent 操作均完成，冻结输入中的全部图片 SHA 都有已完成模型请求的图像传输收据覆盖。该证据证明对应图片字节进入模型请求，不能证明模型理解。

迁移任务由独立步骤设计，将中央尖峰、左下前景改为左右峡壁、弯曲雾谷与右下横向老松。迁移作者没有接收原参考图或原绘制源码，只携带已学方法和新目标，随后确实生成新源码、渲染第三张图片，并由独立评审观察实际输出。迁移不是只有计划或文字结论。
