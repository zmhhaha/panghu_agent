# 通用空间与表面渲染：首阶段

本阶段源自 BV179WZ6REYX 的方法调研及用户确认的 Q1–Q13。对应 OpenSpec 项目
`ec663f5a-53d3-4a0e-9037-933eb788d183`、变更
`improve-video-spatial-rendering-foundation`。代码是本框架原创实现，不安装外部 skill
或接管其制作流程。本文描述源码与本地验证，不表示线上发布或用户艺术认可。

## 接线与兼容边界

新的规划入口显式开启 `VIDEO_SPATIAL_FOUNDATION_PLANNING_ENABLED=1` 后，联合规划输入
冻结 `rendering_foundation`，任务携带 `rendering_foundation_revision=1`。两版规划 profile
只为该标记附加可信合同，要求返回 `video.spatial-rendering-intent.v1`；历史输入、提示
bundle 与无标记结果保留原合同。采用时把 intent 存入 joint plan，随后冻结到 production run。

意图表达空间方案、引擎、镜头动静、必需/可选能力、统一世界光向和质量策略。它不是
能力凭证。正式入口根据空间和真实准入配置选择实现，并保留选择原因、配置摘要与降级
记录。无旁白不是新规划选择 Canvas 的理由；音频或资源依赖可以排除不支持的实现。
备用实现仍须满足全部必需能力，否则在创建付费子任务前拒绝。

Canvas 场景路线目前是静态对象缓存与固定视点2.5D，可用共享XYZ几何指导；Three 模块
路线可表达透视与视点变化。共同语义不意味着同像素实现或七项摄影效果全部可用。模块
作者必须收到冻结意图与质量约束，实际返回引擎也要与所选引擎一致。

新规划开关与已有 `VIDEO_SCENE_SPACE_PRODUCTION_ENABLED` 是两件事。启用前还需部署
工作台接线和准入渲染器、验证准确宿主及资产摘要。旧计划/幂等重放不被新开关重新路由。
本次没有修改线上开关、当前发行包或五分钟影片暂停状态。

## CPU基础机制

在现有 `tools.surface` 添加三个有界表面工具，不修改原接口；采样数值由固定输入决定，
材质工作量另由页面级预算入口累计：

- `evaluateLighting`：对同坐标系法线与 surface-to-light 向量归一化，提供 diffuse/ink
  响应，供留白和墨量组织使用；不实现投影阴影、完整PBR或自动三维重建。
- `sampleMaterial`：固定对象/世界坐标和seed的三尺度变化，提供颜色/粗糙度/法线扰动
  指导；不随帧重新抽样，也不改变几何或实体覆盖。
- `sampleAtmosphere`：有界、随距离单调且可随高度衰减的空气颜色混合指导；不提供真实
  体积散射，不把淡墨或雾的透过率施加到实体覆盖。

渲染能力描述绑定实际 surface 文件摘要与功能范围。图片学习、视频学习、效果作者和
场景作者只有在冻结的准入描述匹配实际导出时才收到新函数指导；旧摘要不获得新能力。
“存在实现/允许表达/已准入/有独立验证”分别标明，函数可用不等于作品已经使用或变好。

实体覆盖、锚点、相对尺度、几何有效性与全程视域仍由原有场景合同/合成器检查。尺度是
作者场景单位及声明的相对约束，不冒充从单图测得的真实米制结构。新增表面工具不绕开
原生内存、几何工作量、缓存、调用时限和实际计量预算。

缓存画稿的二维仿射动画不等于三维物体转动后的逐帧重新受光。新意图明确要求物理方向
光照时，不接受用旋转缓存冒充重新照明；静镜头意图也不能悄悄变成连续运镜。实际三维
旋转与重新照明需要另一个真正支持它的后端。

## 预算驱动的真实材质降级

正式场景请求冻结 host 配置、已知累计用量身份、源码、计划及 surface 摘要，选择带摘要的
`appearance_policy`。host 根据缓存绘制的材质采样估算选择三频段 full，或在纹理为可选
能力且明确允许降级时选择单频段 coarse；coarse 同时关闭材质法线导数计算。必需纹理、
禁止降级、未知用量或最低档仍超估算预算时阻断，不通过换内容或另开学习迭代规避。

策略中的 `estimated_*` 是 host 估算，不是实际消费；缺少显式采样估算时使用缓存像素数，
不能保证作者每像素的调用次数。host 在作者模块运行前安装不可变策略，准入的原始
`sampleMaterial` 导出与 `tools.surface.sampleMaterial` 共用 canonical 预算入口，在执行前
检查余量、累计噪声、角点及导数计算，超限停止；带 fragment 的模块导入、新建合成器及
镜头 seek 均不清空计数。回执须匹配冻结策略、
请求及实际输出摘要，并记录请求/实际参数、原因、预期细节损失和真实工作量。

此预算限于每个页面初始化缓存期间的准入材质函数，不计作者自行实现或其他库的噪声，
也不是整片 CPU 或费用上限。整任务继续使用既有时限、资源约束及累计模型/渲染用量账本。
实体几何、覆盖、镜头、时长、输出尺寸和 seed 不因材质降档而改变。

## 同内容修订

新冻结生产配置声明 `plan_repair_revision=1`。预演发现结构缺陷时，在原一次修订额度内
允许修复布局、几何画稿、光照或镜头；历史配置未声明该能力时仍要求原计划不变。

修改计划必须保留时钟、总时长、视口、世界集合、seed、style、对象ID/kind和来源范围；
递增计划/变更世界的版本及修订消费，保留预算上限和累计用量。复用原 `revise_plan`
生成受影响镜头和缓存失效报告。先校验完整来源，再更新计划账本；旧画稿、计划和预演
保留，新预演使用新摘要与attempt。账本提交后进程中断可恢复，同一目标的CAS竞争不
重复修订或新增模型任务。

这些是声明身份与空间检查，不能证明任意画稿代码没有语义变化。实际画面仍需审阅。
结构错误与必需能力缺失阻断；可选能力未准入时仅按明确策略降级并记录原因。不能借助
恢复、换内容或新镜头清空累计消费；未知用量和耗尽的执行预算不被写成零。

## 固定山水预览与证据

新例为 `video_workbench/examples/spatial-foundation-study/`，基线是保留的35版共同山体，
不是后续四张未采用试稿。保持原山体高程、网格、覆盖回调、对象布局和seed；增加三项
表面指导，并预先确定10秒有限推进。源码、world/plan、逐项关闭对照、覆盖/深度/法线/
光向诊断、连续可播放MP4及可复现runner全部保留。历史样例和冻结输入未覆盖。

本地真实host输出1280×720、24fps、240帧/10秒，检查重复、逆序、重载、全解码、时长
与帧数，并记录对象绘制/缓存和真实helper调用。几何、笔触与纸纹缓存复用；没有为每帧
调用模型。此处只证明本地宿主执行，不能将请求中的历史镜像身份当成已部署新版容器。

同源码预算对照另附 `quality-budget-comparison.png` 与冻结策略。coarse 实测为19,004次
噪声、152,032次角点、零导数，低于20,000次噪声上限；full 的56,835次噪声为18,945次
已观测调用乘以经独立测试确认的三频段推导值，未冒充旧回执的实际工作计数。补入受控
预算后，原九张静图与240帧视频逐字节一致；该样例原生批次累计598.43秒，没有新增模型调用。

评审证据分开：程序检查、模型关键时间窗图片意见、用户连续播放观察、具体版本认可。
本次没有调用生产模型，平台独立模型审阅标为 `not_run`；图像可由本地查看，不声称模型
连续观看/听音。效果采用、WikiSkill发布和艺术认可均未自动发生。

DOF、运动模糊、统一后期、更广引擎执行、GPU、完整连续视听观察及独立部署/发版仍按
OpenSpec后续阶段实施。当前六个已发布WikiSkill不被本次源码修改静默替换。
