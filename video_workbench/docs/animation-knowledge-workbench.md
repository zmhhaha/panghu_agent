# 知识库与整库 WikiSkill 发布

知识页 `/dev/animations/knowledge.html` 是正式制作所用 WikiSkill 的只读版本浏览器。它不是独立知识编辑器，也没有第二套浏览发布版本。本文件记录2026-11-15最终确认的目标；代码、上线及验收另行记录，设计同步不代表完成。

## 效果库快照生成与发布整库 WikiSkill（2026-11-15，讨论确认后实施）

本节替换此前“整库浏览版本与正式 Skill 独立发布”的错误解释。知识库页面浏览的就是正式视频制作使用的同一套 WikiSkill，不再维护独立浏览发布链或人工知识字段。先前页壳上线证据保持原范围，不代表本链路完成。

用户一次明确点击发版，工程冻结当前效果库的不可变快照，记录真实需求、操作输入和输出、源代码、样片身份、生成方法、评价与撤回、失败和停止状态。Agent 通过通用 Agent/Pi 按需读取快照材料，归纳、去重并生成分层、自包含 WikiSkill：原则、适用条件、实现指导、局限、反例及确切来源记录。所有真实记录可作为取材证据；失败可形成反例，未验证推测不能升级成确定能力。参考视频内容须内化为独立能力，不能把网址或外部素材当作运行依赖。

每次生成完整版本，以本次效果库快照为依据；不无条件继承旧版独有知识。效果修改或移除在下次发版体现。无需额外逐效果认可或第二次内容审签；一次点击完成冻结、Agent 生成、自动校验和上线。自动校验包括产物结构、证据成员、内部关联、运行兼容和实际可读取性；不额外制作测试动画，也不把这些检查称为任意题材的审美或迁移验证。

必要环节整版通过才原子上线。失败保留旧线上版本、原快照、任务和失败原因；提交未知仅核对原任务身份，不另建任务重跑。同一发布者并发发版串行或明确拒绝，防止旧任务晚完成覆盖新版本。浏览、刷新、搜索或实验结束均不触发生成或发版。

最近五个成功发布的完整 WikiSkill 版本可供浏览、正文全文搜索及明确恢复线上默认；恢复不重新调用模型。搜索遍历选定版本真实 SKILL.md 和下层文件正文，不只查标题，也不混入工作 Wiki。无版本时真实空态，不导入旧候选冒称已经发布。超出窗口不再供新制作选择，但现有任务冻结和恢复所需确切产物继续保留；本项不是共享框架物理回收。

一次正式制作批次从统筹开始。默认冻结当时线上版本，用户可在高级选项指定保留的历史版；统筹、资源创作、绘制及该批次打磨按需读取同版技能，不按镜头刷新。已采用统筹方案继续使用原冻结版本，不因线上更新而失败。旧项目重新发起完整统筹/制作可用新版或指定旧版进行对比。所有消费者使用真实发布身份，不伪造旧方法的样片/迁移人工认可。

页面只提供发布状态、最近五版、版内搜索阅读和显式设置线上版本；人工内容优化回到效果库。旧经验与冻结合同作为实验事实或历史证据保留，不再要求用户维护另一套知识内容。实施以 O.2–O.7 及相关正式消费任务真实验证为准；设计同步不勾完成，不自动发布生产版本或合主线。

## 2026-11-17：加载选择补充（已上线，真实创作验收继续）

上述“默认冻结当时线上版本”适用于加载知识的制作批次。实验新建、继续优化、从零重做及正式制作统一默认加载动效 WikiSkill，网页和结构化 API 可显式关闭；从零重做不自动关闭。关闭时保留平台技术接口、工具和 HyperFrames 规范，不通过工作 Wiki 或默认方法绕回知识。正式制作从统筹开始固定开关及确切版本，资源、绘制和打磨继承，技术重试不重新取默认。无可用版本与主动关闭须分别记录。

实验室的新任务读取已发布整库的冻结文件原文，沿现有有界输入协议提供，来源标为 `published-release-inline`；正式制作仍使用按需技能工具。两者固定同一 release 或明确的关闭状态，实验室不再将可变工作 Wiki 注入新创作。无发布版时记录真实空库，关闭时不查询发布库。历史任务保留原快照来源。发布、浏览与最近五版规则保持；代码和上线验证见[实现验证](fresh-rebuild-validation-20261117.md)。
