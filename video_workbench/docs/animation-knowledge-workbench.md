# 动画知识库

开发者知识页位于 `/dev/animations/knowledge.html`。目标是选取用户明确发布的整库版本，阅读知识并在该版本内搜索正文。知识来自效果库的真实制作、失败、评价与优化，由 Agent 自动整理；人工调整回到效果库反馈和继续优化，不在知识库逐字段修订。

2026-11-15 本轮已统一与效果库一致的公共页壳并上线，将入口命名为“知识库”。用户手动整库发版、最近五个已发布版本、版内全文搜索和移除人工修订入口仍是待实现目标，见[统一设计 7.21](agent-creation-effect-library-plan.md)。7.20 及本文件末尾保留旧默认阅读布局的真实验收，不将它们当成整库版本已完成。

## 四类内容的边界

| 内容 | 用途 | 修改与生效方式 |
| --- | --- | --- |
| 真实经验 | 保留实验失败、渲染结果、评价等原始记录，作为判断依据 | 正文不可改写；撤回评价后保留记录，并提示引用该证据的页面需要复核 |
| 工作 Wiki 知识页面 | 整理适用条件、局限、反例，以及经验之间的关系 | Agent 根据真实经验提交证据约束提案，经 CAS 自动回写；人工通过效果库反馈影响后续提炼 |
| 已发布整库浏览版本（待实现） | 固定一整套知识，供选版阅读与正文检索 | 只能由用户明确发版；最近五个已发布整库版本可选，不因实验或任务快照自动增版 |
| 已发布 Skill | 给正式视频制作提供已经验收的创作方法 | 保持发布时的版本；修正 Wiki 不会直接替换正式制作使用的方法 |

Wiki 是持续积累的工作知识，后续实验可以读取冻结的任务知识快照。任务快照与整库浏览版本分开；已经冻结的任务输入保持原样。新的方法仍需通过样片、迁移验证与开发者认可，走独立的发布流程才能成为正式 Skill。发布整库浏览版本、阅读或切换版本均不自动发布 Skill，也不改变正式制作的冻结目录。

## 目标使用流程（待实现）

1. 在效果库提供意见并继续优化效果；Agent 根据实际输入、渲染和评价积累知识，保留证据、反例和未验证范围。
2. 需要固定一套可浏览知识时，由用户明确发版；冻结整个知识库的一致版本，记录时间、内容身份与确切页面版本。自动回写、实验结束、刷新和任务冻结都不代替这次操作。
3. 从顶栏“知识库”进入，默认阅读最新已发布整库版本，也可选择最近五个已发布版之一；在选定版内搜索正文、适用范围、局限、反例及相关知识，结果保持版内一致。

没有已发布版本时显示尚未发版，不能自动补发。切换版本用于阅读与搜索，不表示切换正式制作方法。超过五版的浏览入口退场，但任务、知识关系、提案及已发布资料仍引用的确切内容保留；不按每页五版或五个任务快照清理。

知识库取消正文、适用条件、证据、状态和修订说明等人工编辑表单及对应人工写入入口；人工问题回到效果库处理。Agent 的证据约束、CAS 原子回写和未知结果原身份恢复保持。整库发版同样需要幂等和一致性边界，回执未知时核对原请求，不另发新版本。知识读取、全文搜索和刷新均不调用模型、渲染或消耗实验预算。

## 当前实现与后续差距

现有持久层已保存原始经验、每页不可变修订、页面关系、幂等响应及任务冻结快照；Agent 自动提案／CAS 回写已有真实验证。7.20 上线的知识页显示当前页面、目录筛选和单页历史，人工修订仍只是折入高级区域；目录搜索不能等同版内正文全文搜索。目前没有用户手动发布整库的存储和接口，也没有最近五个整库已发布版本。

本轮O.1已完成公共页壳与“知识库”名称的上线和浏览器验收；后续 O.2–O.6 分别完成手动整库发版、五版及引用保留、版内全文搜索、知识只读界面／人工写入退场和完整验证部署。移除旧人工入口前需核对其未确认请求，不能因隐藏表单遗失未知提交；已存在的冻结记录不改写。各项以实际验证和 OpenSpec 勾选为准，不从本说明推断已上线。
