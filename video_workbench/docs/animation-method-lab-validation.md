## 已实现的闭环

实验委托冻结目标、标准、参考元数据、起始候选、方法版本和本次预算。通用 Agent 独立规划、创作和评审，工程层负责持久领取、原任务恢复、隔离渲染和产物核对。一次委托允许多轮探索；目标达成、预算用尽、多种策略停滞、失败或取消后停止，保留最佳候选。开发者可显式开启新委托继续优化，没有累计打磨次数限制。

方法与完整样片分别版本化，以多对多验证关系关联。代表样片与实质不同的迁移结果均须获得开发者对确切版本的认可，方法才可发布。旧测试作品和历史标注不迁移。

主页面改为完整效果样片库，提供前后比较、自然语言反馈、继续优化、异结构迁移和发布确认；方法、源码和执行记录折叠展示。发布仅作用于所选最佳方法，不因淘汰候选的失败阻挡另一版本。继续优化的新版退步时可以保留旧基线。

生产入口采用 methods-only 模式，不加载旧固定样例、不创建旧标注与实验数据库，并关闭旧样例和组件回归路由。旧文件和历史测试数据不迁入新效果库。具体启动方式见 `methods-only-lab-startup.md`。

新 HTML/SVG 渲染器使用既有固定摘要的浏览器镜像，支持 1–60 秒、24fps、正反定位和 MP4 编码。无讲解旁白，允许有目的的音效；声音由受控宿主按 Agent 事件表离线合成并混流，绑定 WAV 和视频摘要。Canvas/Three.js 自由源码尚未在此运行身份中准入。

## 权限、预算和恢复

实验室不持有 Agent 令牌或 Docker socket。私有执行器使用独立方法角色调用凭据，与旧制作及实验室 HTTP 调用凭据分离；未配置新凭据时明确禁用。GET、刷新和打开页面不产生模型任务。新 author/review 角色每次 attempt 的实际模型请求硬上限为 8，包含失败及未知请求；旧角色保持原上限。

委托与渲染适配器分别持久记录唯一领取。未知提交查询原任务，已有渲染领取只核对原产物；外层领取后、适配器领取前的崩溃空隙通过同一操作 ID 恢复。适配器在启动容器前提交自己的唯一账本，拒绝孤立目录，因此恢复不授权新渲染身份。已知失败保留证据并停止。

回归覆盖并发领取、重开恢复、原任务核对、原版仍最佳、候选入库中断恢复、取消后的停止证明、期限约束、错误方法父版本、矛盾评审、跨用户权限及明确的发布视听确认。媒体只从受控接口交付，源码作为下载的 JSON，不在登录来源中执行。

独立审查发现并修复迁移身份与标准混用：迁移只能使用被选方法的准确不可变标准，不能借同名标准替换含义，也不能混入另一委托的基线；入口在产生付费任务前拒绝不一致输入，入库时再次核对完整标准内容。

## 实际证据边界

本地测试使用模拟 Agent 和无执行能力的媒体夹具，不能证明真实模型创作、浏览器容器运行或人工审美。渲染器测试另包含真实 Node 离线声音合成；Docker 与媒体回执夹具不冒充真实容器验收。定向集成 112 项、界面 23 项分别通过；之后的关联改动继续按最终命令结果记录，不把重跑或重叠组简单相加。

新评审协议实际接收并核对静帧模型传输证据。它不能确认完整运动、短暂遮挡、节奏、音效或声画配合，对相应标准必须返回证据不足。开发者实际观看／试听可留下独立认可，原评审及其限制保留，不倒填为 Agent 观察。新角色技术准入器也不授予主观效果认可。

正式制作的方法交付适配模块已实现精确版本冻结、候选读取、零匹配自由创作及逐条采用／适配／拒绝声明。本轮新增独立 `video.animation-production.v1` 合同与 `video.creative-scene.v2` 包，并接入普通工作台的候选、采用及隔离渲染代码；真实新角色技术准入和线上接通仍需另行记录。方法交付、自报采用和实际媒体体现分别记录，不把源码锚点或模型自报作为已观察的效果。

该适配模块要求独立持久化冻结账本，先保存选择意图再请求方法交付收据。即使在收据保存后、快照返回前崩溃，恢复也使用原方法集合；无匹配结果也不会因后续发布而改变。新增崩溃、并发、新版本发布与身份绑定回归共 12 项通过。新启动模式及原代理边界相关测试 174 项通过；界面 23 项通过；迁移与委托协调器最终 12 项通过。各组有重叠，不累计为唯一测试数。
