# 动画实验成果进入正式制作

2026-11-08；开发分支 `codex/video-capability-experiment-redesign`。

## 要解决的问题

实验室已经可以让通用 Agent 编写可定位时间的 HTML/SVG 动画。正式工作台却只接受受限 motion/process JSON，再交固定编译器生成画面。实验指导语和自由动作无法越过这个边界，只复制 prompt 不足以解决问题。

本轮补齐“实验反馈 → 发布能力策略 → 真实旁白与文稿 → 生成源码候选 → 隔离渲染预览 → 明确采用 → 冻结整片导出”。普通用户不需要操作实验页、选择引擎或管理策略版本。

## 设计

能力策略作为仓库内不可变版本包发布，包含适用目标、引擎、规则、实验来源、证据与摘要。实验与正式制作读取同一份包；未发布指导语不改变生产默认策略。新版本影响新任务，已生成候选和冻结快照保留实际输入及策略，不随默认版本变化。

复用通用 Agent 已有 `video.animation-experiment.v1` 创作协议，不改写冻结 v1 profile 或引入另一套长期 Agent 服务。业务适配器显式输入场景语义、旁白、当前采用录音的摘要和实测时长、beat 时间与已发布策略。产物是可执行源码，必须按不可信代码处理，不能嵌入已登录的工作台网页运行。

源码候选与既有 motion/process 共用项目归属、操作、取消、候选、采用和时序审阅机制。旁白或录音变化使绑定不匹配的候选失效；不得对按录音创作的代码悄悄拉伸时间。镜头前后留白由可信适配器将源码时间钳制在起始或末尾状态，不改变录音与源码内部节拍。新快照类型可组合旧编译动画与源码镜头，冻结源文件、音频、策略、创作输入、渲染适配器与运行资源。既有 v2/v3 快照含义保留。

首版正式准入 HTML/SVG。Canvas/Three 的自由生成需要各自执行与观察验证后再启用，不因实验组件可播放就自动扩大生产准入。源码镜头采用绝对时间 seek、隔离 Chromium 截帧和 FFmpeg 编码；旧编译动画继续 Hyperframes。两条路径复用同一内部 K8s 执行、无凭据/无外网边界、原声合成、输出验证及取消恢复。技术检查证明源码可执行与时间可复现，不自动证明画面审美或内容正确。

## 验收与依赖

验证策略输入绑定、过期拒绝、归属隔离、候选采用、历史复验、音频完整、反向定位、混合整片导出和浏览器操作。使用真实文稿与录音的新任务验证，单独记录模型调用次数与失败，不重用或重置上一轮四个已结束的实验槽。

共享 Agent 的实验 profile 注册仍受既有隔离任务恢复问题影响，归属 `harden-shared-platform-production-readiness` 的 P3。不清理旧任务配额或伪造停止证明来绕开准入；代码接入、隔离验收、共享路由启用、线上可用分别记录。公共渲染服务拆分、框架计费与存储回收不纳入本次业务任务。

## 实施状态

正在实施。正式路由启用、真实新任务、浏览器采用/导出和部署结果须以本轮实际回执补充，不以设计文档代替完成。
