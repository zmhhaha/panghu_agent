## 原站与服务器实测

使用用户提供的 B 站《万物》（`BV1BxWu6SESe`）做有限观察。原片 111 秒，当前未登录状态可访问最高为 852×480。服务器可信执行器内请求 38 秒：完整 detail 帧 852×480／136337 字节，中心半幅 crop（x=.25，y=.25，width=.5，height=.5）为 426×240／32941 字节。两次实际 PTS 均为 608000 × 1/16000 = 38.0 秒，图像 SHA-256 已核对。

两次按需网络读取分别为 7619627 和 6849502 字节，分别受 32 MiB 上限限制；没有保存完整参考视频。每次观察完成后任务临时目录为空，外层临时目录也已删除。检查不创建业务作品或调用模型。读取使用 AliDNS 的受控公网解析，仍保留 TLS 和目标地址检查。

修正后同一服务器对原片 111 秒范围实际提取 24 张 overview：耗时 14.926 秒，瞬时读取 107676186 字节、51 次请求，均未超出单次 128 MiB／128 请求预算；24 个独立 PTS 全部核实，完成后临时文件和外层目录均清理。该检查同样没有调用模型或创建业务作品。

线上网络策略仅增加可信执行器到公网 TCP 443 的出口，保留原 DNS／Agent 出口和全部 ingress，排除私网、链路本地和代理 Fake-IP。渲染容器与 Agent 工作容器网络能力未改变。
