# ink-landscape 的知识与代码消费

2026-11-20。本变更把独立笔墨代码库的调用说明、固定版本代码和图片／视频学习的实际渲染接起来。OpenSpec 项目为 `ec663f5a-53d3-4a0e-9037-933eb788d183`，变更为 `add-ink-landscape-wikiskill-integration`。源码、技术验证、线上执行、艺术质量和知识发版分别记录。

## 三部分的职责

开源仓库的 `skills/ink-landscape/SKILL.md` 提供创作入口，四篇 references 分别说明笔墨皴法、墨水事件、树石鸟与可编辑源、运行及验证边界。Agent 自行决定构图、物象、原始笔路、笔序和组合；宏是可替换的便利接口，不固定完整山水模板。

代码库作为 `drawing_libraries` 提供 Canvas 2D 画面能力。它与 `canvas` 绘制引擎、GSAP／Anime.js 动作编排分别声明。HyperFrames 继续驱动图片的单帧定位和视频的绝对时间；本库没有新增 Shader 后端，也不要求 GPU。

知识发布沿用开发者手动整库快照和编译流程。快照会收录当前 image-owned 库的版本、API 说明、使用限制与依赖身份，编译 Agent 据此生成 WikiSkill。代码安装、目录刷新和实验完成都不发布新版本；旧发布正文不会因本库接入而被替换。最近五版及冻结选择的规则继续适用。

## 固定版本与本地导入

当前固定 `ink-landscape@bb7338a5c57d4151c3d8635a8549057bb0383ca0`，包版本 `0.1.0`。`vendor_ink_landscape.py` 从干净 Git checkout 使用固定 esbuild 0.25.12 构建 ES2022 单文件 ESM，保留 MIT 许可及来源 manifest；技法说明也按内容摘要固定。资源禁止 Git 行尾自动转换，Windows 与 Linux 按同一字节验摘要。

学习输入的 `constraints.drawing_libraries['ink-landscape']` 提供版本、修订、入口及资产摘要。当前模块入口为 `./assets/ink-landscape.mjs`，可在 Agent 交付的 `scene.js` 中作为 ES 模块导入。`renderCanvas()` 接受真实 2D 上下文与 `InkScene`；墨层使用 `renderInkProcess()`。创建数据文档本身不会产生像素。实际作品应保留原始配方、路径、种子和库修订。

库代码随 executor 镜像供应，再通过已有只读渲染输入挂载进入隔离容器。学习宿主只接受固定 descriptor 和真实文件摘要，不访问 npm、CDN 或 GitHub。基础 Method 与正式影片没有因此获得这份新依赖；正式环境必须另行准入和验证。

启用知识时，学习任务读取自己冻结的发布版本；库依赖不匹配的包不能悄悄配上新版代码。关闭知识时，不注入本 Skill 或从另一个入口恢复同一套技法说明。运行时名称、版本、入口和调用约定属于工具接口；任务明确提供的参考、API 资料及基线源码仍可使用。

## 验证方式

本地模块实际加载、库函数执行、库产物进入可见画面、可重复输出和画面质量是不同结论。检查应同时保留冻结任务、Agent 原始交付源码、库代码与许可摘要、真实 PNG／MP4 和宿主回执。源码检查说明调用与数据如何连接；宿主侧执行记录核实发生了调用，实际成图用于判断表现。

单帧只能验证画面。绝对时间重放通过不能代替连续播放评价；有限湿态事件也不等同真实纸张流体。成功导入、测试通过和笔触数量均不表示参考相似度或用户艺术认可。最终测试、生产部署与产品试验结果由本次验证记录补充。
