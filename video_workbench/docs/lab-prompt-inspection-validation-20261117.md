# 动画实验需求与 Agent 输入查看验证

日期：2026-11-17。本轮已推送开发分支，从干净 Git 完整构建并上线；未合入主线。精简[机器回执](evidence/lab-prompt-inspection-20261117.json)记录镜像、自动与实际只读验收。

## 用户入口与行为

在动画效果库打开某次实验详情，展开“本次提交需求”或“各轮 Agent 输入”。两处默认折叠，展开后通过只读 GET 按需读取；查看、刷新、复制和下载不会启动生成、推进任务或消耗制作额度。

“本次提交需求”展示表达目标、修改意见、标准、能力选择与预算等字段，提供复制需求文本和 JSON 下载。“各轮 Agent 输入”先展示规划、创作、评审及协作阶段索引，打开具体任务后读取其真实冻结输入，可复制本轮需求文本或完整 JSON，并下载输入 JSON。正式页面的布局预览不读取任务输入。

## 记录来源与边界

- 新请求首次持久保存原始结构化提交。快照位于委托记录的独立字段，不改变冻结执行请求或原有幂等摘要；同一请求重放保留首次快照。迁移实验记录用户实际提交的外层表单。
- 历史任务没有原始快照时，明确标记为“从冻结字段还原”，不补写为原始提交。历史预算是 `creator/review/render/seconds` 执行计数；原始请求预算为 `max_rounds/max_seconds`，两者分开展示。
- 具体任务输入来自持久化的 `op.input`，附原 `input_sha256`。读取时核对数据合同与摘要，不依据当前配置重建历史输入，也不补写未保存的完整系统 prompt、模型对话或固定执行合同。
- 本轮范围为主委托的规划、创作、评审及协作分工输入。Manim recipe 等资源生产者使用独立账本，尚未纳入本页；图片输入保留冻结文件引用与摘要，不包含图片字节。
- 接口核验登录身份、委托归属、操作归属与删除可见性。执行凭据、claim token 和宿主私有路径字段不开放导出；无法安全展示的操作以稳定原因说明。账本完整性异常时拒绝读取。
- JSON 复制和下载保留输入内容；SHA-256 对应 canonical JSON，不能用排版后的下载文件字节直接比对。公网只调整索引读取链接，不递归改写原始提交或冻结输入中的 URL。

## 只读接口

公网 API 位于 `/dev/animations` 下：

```text
GET /api/method-lab/commissions/{commission_id}/prompt-inspection
GET /api/method-lab/commissions/{commission_id}/operations/{operation_id}/input
```

索引返回需求来源、有效冻结需求及操作摘要，避免把可能较大的完整输入放进详情轮询响应。具体输入通过第二个入口单独读取，采用独立有限 JSON 响应大小。客户端应使用索引返回的站点根相对 `input_url`，不重复添加 `/dev/animations`。
