# 整片有声草稿编排验证

2026-11-13，实施 `evolve-video-agent-creation-and-effect-library` 的3.3。用户采用一份整片方案后，点击“制作整片有声草稿”，依次生成全片配音、按各段实测录音制作创意动画，再合成一份整片有声草稿。项目统一音色，默认无字幕。

## 实现边界

制作记录保存在工作台SQLite，冻结方案、场景顺序、内容依赖、音色、读音和前后留白。每次子任务先保存稳定请求键，再调用现有音频、通用Agent／Pi创作及Hyperframes渲染路径；刷新或重启按原键找回，不提交新的付费任务。暂停新任务准入后仍跟踪已有任务的恢复和取消。

所有配音完成并通过WAV实测、摘要和原文绑定核验后，才开始动画。每段录音与留白合计最多60秒，场景最多24段，全片沿用既有总时长限制，不把单段60秒误作全片限制。音画由内部确切版本对绑定，不依赖用户逐镜采用；内部候选不会更改用户采用指针、试听状态或人工时序核准。

内容变化会停止后续任务并取消、追踪仍在运行的子任务。动画提交未知时继续查询原任务；语音提交未知或停止未确认时阻止重发。草稿播放器及下载只呈现该次确切制作结果。整片镜头新增或重排后历史草稿显示内容已变化；已冻结的旧视频保持可读。

## 本地验证范围

新编排测试使用真实SQLite与WAV，覆盖重启恢复、丢响应、请求幂等、权限／CSRF、失效、取消及不自动采用；音频、Agent与远程渲染使用可控替身。双段整合测试使用真实MotionStore、候选绑定和Production快照，实测录音加留白为4.5秒。13段回归验证实测全片74.75秒仍可进入动画阶段，单段含留白超60秒拒绝。

候选桥接另外覆盖准确版本对、录音被篡改、语义／音色变化、整片顺序与遗漏、真实时钟、禁止正式交付／字幕参数、历史当前性及不写人工认可。前端组合回归105项通过，包含刷新找回、未知提交仅GET、跨面板互斥、播放器互斥与项目切换。Python集成检查及实际发布、网页运行结果将在取得证据后补充。

本地验证不能代替真实TTS／Agent／Hyperframes整片运行，也不证明用户已认可画面、配音或时序。跨段共享状态3.4、独立整片媒体审阅及一轮自动修订3.5、包含已发布方法的真实新项目验收3.6属于后续任务，本轮不提前勾选。开发分支不合主线。
