# 完成配音后直接试听

更新：2026-11-03。用户认可上一轮连续图解的画面方向，要求继续完善工作台体验。本轮针对换音色后不容易找到新配音的问题；开发分支仍为 `codex/video-hyperframes-motion`，未合主线。

## 使用方式

配音任务完成后，本次结果有效且尚未选为试听版本时，任务提示旁会显示“试听本次配音 A编号 · 实际音色”。点击后，播放器切换到这次任务对应的录音并从头播放；正在比较的旧版本不会因为后台刷新而被自动切走。

按钮对应的是这次任务的确切结果，不泛称所有历史录音中最新的一条。上传任务显示“上传录音”，不会推断其音色。已过期、失败、取消、结果缺失或不匹配的任务不提供这个入口；历史版本仍可通过原下拉框试听。浏览器拒绝播放时，界面提示已切换的配音编号，并保留播放器的手动播放按钮。

试听不会采用录音、保存尚未提交的项目音色、提交新的制作任务或确认人工时序。整个项目仍统一选择一个音色。保存音色后的提示说明：有效的动态图解可继续使用，配音需重新生成、试听采用，再核对画面时序。
