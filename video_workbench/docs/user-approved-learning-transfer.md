# 用户认可后再做换内容验证

日期：2026-11-25。此规则替代图片、视频学习中“复现结束后自动做一次换内容验证”的默认调度。代码、部署与验收分别记录；历史实验及其冻结输入保持原身份。

## 默认流程

新建学习、继续优化和从零重做只观察参考、创作、真实渲染、独立对照评审，并在本次预算内改进复现。达到轮数、评审建议停止或没有清晰改进方向时结束本次流程，保留实际产物及问题。

复现结束后，换内容状态为 `awaiting_approval`。这表示尚未由用户发起验证，不表示复现已经达到审美目标，也不表示验证失败。内部评分、最佳候选、评审建议和剩余预算都不授权换内容；即使模型返回了建议任务，协调器也不自动启动规划或创作调用。

新实验冻结 `transfer_policy: "manual"`；作者和评审输入的 `constraints.transfer_policy` 声明 `mode:"manual"`、`automatic_transfer:false` 及本次认可范围。它明确本次调度范围；旧目标文本中“预算内做一次迁移”的历史措辞不恢复自动执行。原版角色包仍支持显式 `transfer_plan`，其存在不表示普通复现应调用该阶段。

## 用户认可具体版本

用户查看一份实际生成的复现作品，选择“认可并验证换内容”，在独立表单确认具体版本和验证预算后才提交。打开表单不会发起模型请求；表单绑定打开时的候选身份，不因轮询、当前选择或内部最佳变化而换成另一版本。

来源必须是同一 owner、同一项目内的复现作品，已有实际图片或视频及可迁移方法。只有源码、尚未渲染、属于其他项目、换内容作品本身或缺少方法的候选不能使用。AI 评审和分数不是用户认可的前提或替代；用户可以认可已经渲染但尚未完成独立评审的作品。

认可绑定该候选的身份、源码及实际媒体摘要、请求编号、认可者和时间。该动作不改变已采用默认作品，也不采用后续生成结果或发布 WikiSkill。

## 同一结构化 API

图片和视频共用原有实验入口：

```text
POST /api/picture-lab/projects/{project_id}/experiments
POST /api/video-lab/projects/{project_id}/experiments
```

```json
{
  "request_id": "独立且稳定的请求编号",
  "mode": "transfer",
  "base_candidate_id": "用户明确认可的实际复现作品编号",
  "approve_candidate": true,
  "max_rounds": 1,
  "max_seconds": 3600
}
```

`approve_candidate` 必须是严格布尔值 `true`，`base_candidate_id` 必须明确提供，不能隐式使用内部最佳或默认作品。验证是单独的新实验，固定一轮，时间预算默认3600秒。开始后冻结来源和输入；运行中不能切换认可对象。

两库 `/catalog` 的 `capabilities.transfer` 公布 `automatic:false`、`requires_user_approval:true`、`experiment_mode:"transfer"` 和默认的一轮／3600秒预算，供外部 Agent 查询当前调度能力。

旧的 `continue`、`fresh`、`retry` 语义继续独立。普通优化不夹带认可字段或隐式验证开关。活动实验和执行是否停止尚不确定时，不能叠加付费实验。相同 `request_id` 和原正文恢复同一请求；回执未知时先读取项目，不能换编号重复提交。

## 规划和验证的数据范围

显式验证先由独立规划角色基于获认可的实际作品及其自包含方法提出一个有区分度的新任务。原始参考图、原参考视频及复现源码不作为规划输入。

随后创作者只得到已形成的方法、新任务和必要的运行合同。原图像、原源码、专用 world/plan、原优化意见、原复现评语和发布知识快照不混入该创作输入。宿主支持的绘图 API 及资产属于运行能力，不属于待验证方法的额外艺术指导。

新作品经过真实渲染及独立评审后，分别记录复现与换内容证据。图片只支持静态结论；视频仍按实际观察范围记录连续运动与声音的局限。用户认可来源作品，不等于已认可新任务结果或证明方法普遍有效。

## 历史和技术重试

旧实验、失败、源码、产物、审批和冻结输入不原地改写。旧自动换内容失败不能通过“技术重试”绕过新认可入口，必须回到真实复现作品明确发起验证。

已获认可的手动验证技术失败，可保持原认可来源及冻结输入恢复失败阶段；规划失败恢复规划，渲染失败恢复同一来源的渲染，不能静默重新选择来源、生成新审批或把历史作品复制成新产物。

旧复现技术重试保留原输入与证据，新实验的协调器也不因此自动接续未认可的换内容验证。

## 其他成果与知识发布

效果库既有“验证不同结构”是显式用户操作，继续保留；本次不扩大它的自动执行范围。采用默认作品、图片转关联动画、换内容验证和 WikiSkill 发布仍为独立动作。

本次发布验证应使用确定性测试、角色桩及只读页面检查证明默认不调度额外调用；不能为了验收该功能而替用户认可真实作品、发起付费验证或发布知识。
