# Canvas适配与可复核参数

## 结构和覆盖

宿主提供SceneSpace artwork API revision 3、对象缓存、独立paintCoverage、共享几何
及surface helper。作者paintObject接收对象/世界/tools；paintCoverage返回局部实体
覆盖与承载纸色。资源闭包、能力准入、预算和绝对时钟由宿主管理。本方法不改变
公共接口，也不把已写出的作者代码当作已准入运行环境。

局部投影的position、normal、depth和flow必须来自同一份共享表面。明确法线坐标系，
把light转换到该坐标系再比较。固定正交相机不是最终二维取景相机；后者的推移不
重新定义山体表面法线。depth表示投影可见面排序，不代表对源图进行了三维重建。

## 光向与结构纹理

evaluateLighting的normal/light必须是非零有限向量；方向会归一化。diffuse表达朝向
响应，ink模式允许用显式lightRange对响应做平滑映射，供绘画落墨而非通用物理材质。
ambient是作者允许的暗面最低信息，不是完整环境间接光。参数应从本幅意图决定，
不能照抄某个太阳坐标，也不把一切暗部当作投影阴影。

sampleMaterial的position取对象或世界坐标；seed固定。scales表示递增空间频率，
weights决定各频带贡献，base/amplitude控制值域，roughness相关参数提供表面响应
线索，normalStrength控制可选扰动。解释尺度对应什么现象，再把结果接到笔触或
已准入材质。这里的返回值没有实体alpha；其变化不改变后山是否被遮住。

墨笔规划可以共享同一结构区权重：先少量湿接触组织暗面，再以长短/方向/干湿不同
的皴擦建立岩面，最后在少数脊路转折或交汇点落焦墨。长笔需沿途检查光向和表面
连续性，不只看起点。轮廓只在有意强调的地方连贯，不包住全部三角面。

## 距离空气与云

sampleAtmosphere中near/far/distance需相同单位、相同意义。density/strength/
maxAmount限制最大影响，height与heightFalloff是可选高度权重。返回amount/
transmittance/color用于颜料对比或颜色混合；不要把transmittance传给实体覆盖。
雾的距离效应与云带的构图遮挡可以共同使用，但须防止同一遮罩重复作用。

远近线索先考虑覆盖、形体尺度和笔触，再看对比与色温。主体被雾洗平时先减少雾，
不要用极黑细线重新圈出全部轮廓。保留水墨纸白时，背景统一介质纹理应稳定，
不能逐帧换噪点形成闪烁。

## 镜头与缓存

二维取景的中心和zoom属于完整计划。单层取景范围可从中心和viewport/zoom反算；
有视差时需逐层计算实际矩阵。验证完整运动范围，不能只看开头和结尾。缓存密度
按计划中的最大放大倍率准备；边界不足时修计划或明确扩展场景，再做渲染。

一个本地测试使用24fps、10秒、240帧，起幅短暂停留后缓慢推进7%，保持末幅；
它证明了该方案可复用对象缓存，不构成任何影片必须如此运动的模板。全部层保持
相同视差时，这是统一裁切推进，没有新增立体环绕。需要差异视差应另看深度层关系，
不能把同一二维平移自动称为真实三维相机。

## 资源账与可选降级

完整三频材质一次查询通常执行三次噪声求值；低档可只执行低频一次，并关闭材质
法线导数。具体实际work应由准入helper记录。每页初始化共享同一canonical计量，
直接/fragment导入不能获得新额度；重载新页仍要花外层任务时间，不宣称整个任务
仅消耗一次初始化。

estimated_requested_noise_evaluations、estimated_selected_noise_evaluations是估算；
material_noise_evaluations是实际扣记。不能把full样本调用数乘三的推导写成原本
没有记录的旧宿主噪声计量。记清推导来源和计数范围。没有计量证据就保留未知，
不要将未知历史成本清成零。

## 适用引擎与限制

本候选运行要求仅声明Canvas。共享XYZ网格和固定正交投影帮助二维笔触组织结构，
并不提供封闭几何、任意相机角度、自动PBR材质、真实自阴影、HDR环境照明、GPU
加速、物理景深或快门模糊。SVG与Three可以内化概念，但需要各自真正的组件、
运行合同和样例验证，不能凭平台列出了引擎就宣布效果已完成。
