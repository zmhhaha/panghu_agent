# 何时使用

当已有画面出现山峰各自孤立、笔纹不顺形体、前后像贴片、纹理随物体滑动、镜头推进时
暴露空边，或每次改效果都重新生成场景时，使用这套工作方法。先查现有场景与宿主
能力，再决定局部修改；不要把本候选变成所有影片的固定山水模板或强制后期清单。

本候选在Canvas、共享XYZ高程网格、固定正交投影和独立实体覆盖的宿主上做过本地
原生验证。三维网格是作者组织形体的输入，不是从参考图测出的真实三维。SVG、Three
可以参考相同的思考顺序，但本候选没有它们的成片实测，不据此准入新引擎或组件。

# 先分清结构、画法与成像

结构回答“是什么、在哪、谁挡住谁”；画法回答“哪里落墨、笔怎么走、浓淡干湿如何
组织”；成像回答“怎样把已渲染的颜色交付到屏幕”。先检查共同形体、比例与覆盖，再
调整笔触/材质，最后才评估曝光、色调映射或介质纹理。全图噪声、暖色叠层和模糊不能
补救错山形、错光向或透出的后山。

实体的淡色与透明度必须分离。浅墨山可以颜料稀，却仍有不透明的纸色承载面；其后山
应由宿主按实体覆盖遮住。雾、水或纱确需透光时，应由场景明确声明。不要把这项合成
职责写成“遇到浅墨山就多画几笔黑线”的风格禁令，也不要在最终合成画布挖洞假装留白。

# 在写细节前冻结一个可检查的画面

保留当前对象、位置、尺寸、种子、关系和视点；给本次要改的内容与要保护的优点各写
一段。若主体由多峰或多个部件组成，先检查共同基座、连接、前后关系与轮廓。自然山
不是等距摆放的独立圆锥。结构可用共享网格、深度场、表面或可靠的绘制排序表达，
不要为使用某种技术名词而替换已经有效的结构。

把coverage、可见深度、法线和光向引导作为独立诊断输出。确认诊断真的生效，尤其是
缓存密度与缩放下不能出现逐像素小矩形之间的接缝。诊断图用于定位，不作为最终墨稿
下面的一层灰色机器阴影。先看整体与轮廓；放大细节不能代替完整取景。

# 用同一表面协调光向与笔触

用与表面法线同一坐标系的主光方向，计算朝向响应。Canvas的
`tools.surface.evaluateLighting(normal,{light,mode:'ink',lightRange:[a,b]})`
可以给出lit/shade/ink_density；它是作者明暗组织的指导，不是完整的投影阴影求解。
光源画在画面哪里、主光方向和笔墨明暗不应各自独立。

让湿笔、皴擦、勾骨共享结构墨团、种子和光向；长笔沿途复核表面与明暗，进入安静亮
面时提收，遇到深度跳跃时断开。亮面应有留白，暗面可有连贯墨腹，转折处少量焦墨
提神。具体黑白比例来自这幅画的意图，不套用一律“右白左黑”或一律铺满细排线。

不要直接描全部网格边。轮廓需要宽窄、提按、干湿和断续；密集等宽竖线会变成拉丝，
任意散点又会削弱山骨。把笔触沿形体走、聚散和焦点位置放在同一个计划里，再判断
是否需要横向/斜向短接触打断过分顺滑的长纹。

# 材质从对象坐标生长

选择对象坐标或共享世界坐标，并解释其用途。会动的独立物体通常应在自身坐标上取
纹理；共同地形可在同一世界坐标上取样。位置、种子和尺度固定后，同一位置重复求值
应一致，不因前一次seek、时间或渲染顺序改变。

`sampleMaterial(position,{seed,space,scales,weights,base,amplitude,roughness,...})`
可给出三个尺度的变化与粗糙度线索。把它们接到已有笔触的墨量、宽度、干湿或有意义
的材质参数。不要把随机噪点本身当作岩层、木纹或毛笔；会改变外轮廓的细节仍需由
形体或真实笔触表达，不能只靠颜色贴图冒充。

在水墨场景中，这类采样只适度调整沿结构的接触，不把平滑的PBR阴影覆盖上去。
纹理尺度和主体尺度要一致；不能因近景放大而把细纤维变成巨大的裂缝。对写实材质，
颜色、法线与粗糙度是不同通道；本候选没有实现或验证完整PBR、HDR环境反射。

# 空气降低颜料对比，不取消实体

按明确的作者距离或已知深度组织远近。可用
`sampleAtmosphere(distance,{near,far,density,strength,maxAmount,height,...})`
得到amount/transmittance/color，再调整着色。距离、身高和空间轴不能与屏幕Y随意
互换；未知深度应明确保留为未知，不包装成实测距离。

transmittance用于颜料/颜色响应，不等于实体alpha。远山的颜料可以更淡，但仍通过
独立coverage处理遮挡。墨色、笔触尺度、清晰度和云雾的前后穿插共同建立景深，
不能只有一条水平白渐变把全部山脚切齐。云有方向、厚度、留白与遮挡职责；先避免
同一雾alpha在coverage和雾层重复相乘，再判断画面是否确需更多雾。

保留大片安静留白可以是绘画意图。“空而光滑就是错误”仅适合某些细节密集的写实
题材，不能变成水墨、极简画面或水面的通用要求。

# 先编排镜头，再探索已有世界

在初始计划中决定这个镜头应静止、推进、平移，还是保持镜头而让场内局部变化。
每种运动要有展示关系或揭示信息的目的；没有必须动镜头的默认规则。保留可读的
起幅与落幅，选择有限、可解释的主运动，不用不断新增山、树或装饰代替镜头设计。

静态形体、笔触布局、纸纹和可复用材质在初始化时建立，之后按绝对时间求相机或
已声明的局部动画。相同时间、逆序、重复、重载应稳定。固定随机种子，不依赖墙钟
或上一帧累积。分辨率、缓存密度、视差参数和最大zoom须在开始前确定。

检查完整镜头范围的取景矩形与overscan。已有画布足够覆盖有限推进时，直接复用；
需要平移露出更多场景时，先规划边界，不在边缘露馅后无止境补画。固定正交投影的
2.5D缓存可支持有限推移，不能被说成能绕山看到背面的三维世界。角度改变到需要
未绘制表面时，应视为新的结构工作，而不是盲目放大位图。

景深与运动模糊是独立成像机制，逐帧截图不自动具有它们。物理景深需要焦距、光圈、
焦平面与空间尺度一致；快门模糊需要多个时刻与相机/物体状态的真实积分。大场景的
广角本来可能很清楚，不为显眼而放大光圈做成微缩玩具。本候选没有这两项实现。

# 用同内容对照解释变化

固定场景、源身份、几何、布局、seed、机位、时间、分辨率和资源字节，分别关闭一项
引导，和全开结果并排。每个条件独立冻结参数与输入。修改多项时如实称为复合迭代，
不能把全部改善归因于某个参数。光向或材质影响笔触选点时，记录这种因果传播，
不要声称只有最终像素颜色发生变化。

诊断、全图、关键局部与时间拼图各回答不同问题。技术检查可以证明输出尺寸、帧数、
完整解码、求值一致与缓存复用；静帧不能证明连续运动手感、声音或完整影片质量。
记录“时刻·位置·具体问题→改什么·保护什么”，不以一个新题材的分数替代当前画面
的用户认可。当前内容未达预期前保持内容打磨；迁移需依据用户认可的效果再决定。

# 成本与降级

复用场景通常减少反复创作与模型调用，不代表光照、阴影或子帧渲染免费。分别记录
初始化、缓存、帧合成、编码、模型及审阅成本。HTML字节数不能代表显存、纹理内存
或出片时间；某台GPU的每帧耗时不直接适用软件渲染环境。

可选纹理超出预算时，宿主可以把请求full降为实际coarse，并记录损失。现有低档只
计算低频、跳过高频和材质法线变化，不能改动几何、覆盖、时钟或输出尺寸。此策略
由宿主和canonical helper预算强制执行，作者的Skill文字不是计量器。保存请求参数、
实际参数、原因、预算和真实work；估算字段与实际扣记字段分开。没有明确允许时，
不要自行牺牲必需结构、比例或覆盖去换分数。

默认一轮学习与预算由任务控制。本候选不将外部示范的至少三轮、十五轮或某一秒数
写成全平台默认，更不授权新模型调用、换内容验证、效果采用或正式知识发版。

# 证据与交付

交付自包含方法、适用宿主、参数含义、失败、边界和可复核的输入/输出身份。将外部
网址与原始观察放在独立研究记录，不成为运行依赖。清楚区分视频所述、读源码确认、
本地测量与尚未验证的推断。本候选的本地样片是10秒有限推进、无声、Canvas原生
host验证；有静态看图、帧数/解码/确定性与成本证据，没有GPU性能、连续视听、
跨题材迁移、用户艺术认可或正式采用的证明。
