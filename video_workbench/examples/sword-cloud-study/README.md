这是一次新的手工代码试画，保留前轮失败，不改写图片学习实验的状态。

本例作者源文件为 `scene.html`、`scene.js`，未使用可选的 `scene.css`。`plan.json`
由场景宿主单独读取，不扩充作者源文件集合。使用当前能力 descriptor 和固定
ink-landscape 资产进行正常绑定；源码不加载网络或来源图片。原参考只用于判断意境。

七层十对象保留独立物体缓存。山峰横截面点网组织下行皴线，折肩轮廓与内部笔路
分别组织；不使用法线灰阶着色。山脚覆盖在局部缓存中处理，另以独立云雾对象在山体
与近岸之间合成。近岸由颗粒干擦、相连岸脊与局部露纸组成，针叶按簇组织。
图中太阳按山体后的光源意象处理，没有另一束独立的左前高光。

笔路模块小规模移植 Lingdong Huang 的 [{Shan, Shui}*](https://github.com/LingDong-/shan-shui-inf)

固定资产与噪声接口，仍保留其原许可与准入。

真实桌面 Chrome、现有 HyperFrames/场景宿主完成单帧渲染，重复、逆序及重载图像
一致。摘要、实际上下文及来源边界见 `evidence.json`。本轮没有 ARM 容器、正式长片
或模型学习循环验收，也未部署任何运行时改变；没有新增外部模型调用。

上一版获得用户对剑峰、云海、飞白和远山构成的积极评价，用户继续要求微调局部纹理。
