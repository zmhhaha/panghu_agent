# 共同山体：笔墨疏密试稿

2026-11-23，在 [共同山体结构版](../shared-mountain-study/README.md) 上继续调整画法。
旧版完整保留。本例的共同网格、相机、原始深度/位置场、实体覆盖和单帧计划与旧版
逐字节相同；变化仅在作者 `scene.js` 的笔墨、近岸与松树画法，不改变框架架构或运行时。

这次观察到的格栅感并非真正绘制三角网边。旧稿叠加大量顺坡长线、近横向坡肩擦及
细皴，形成纵横交叉；直接使用逐三角面方向也会强化折转。新稿在深度邻域内平滑
法线/流向建议，笔路采用惯性变化；可见性与跨面断笔仍使用原始深度/位置，几何不变。

画法调整如下：

- 宽皴上限从主峰420改为185，细皴从2200改为540，坡肩候选从480改为110并再次按
  朝向/概率筛选。实际落笔量还受间距、可见性和路径长度限制，不能把这些上限当计量。
- 通过可变间距的拒绝采样组织墨簇，亮侧少笔，暗侧及少数沟壑较密。光向是画面右上
  红日在山后的作者假设，用来选择墨笔位置与浓淡；没有执行完整物理阴影求解。
- 湿笔只在少量暗部叠加；长皴保留岩壁联系，短横折局部打断，脊线仅描有提按的片段。
  前几张大灰底或硬色块试稿已淘汰，未作为本例输出。
- 近岸粒子笔按落点间距和落印面积换算透明度，缓解同一笔反复盖章导致的过饱和；
  增加不规则岸脊联系、少量露纸通道及选定暗核，树根仍有支撑。
- 松干采用平滑弯曲笔路，枝条基点跟随树干，针簇加密并保留前后浓淡；右侧配山退淡。
- 只在对象局部墨迹中加入很轻的纤维缺墨，不加全图灰罩。纸纹不能代替造形、留白与
  墨色组织，也不能证明画作具有真实毛笔物理。

`scene.html`、`scene.js` 是作者文件，`plan.json` 由宿主另读。需要已冻结的 API3/
`tools.geometry` 与固定 ink-landscape 资产。只生成一次共同网格及静态绘画缓存；
本例是固定视角单帧，不据此验证动画、三维环绕或完整视频。

桌面真实 Chrome 的重复、逆序和重载检查见 `native-evidence.json`。同一已上线运行时
的新旧 ARM 两图、独立账本、资源及保留数据核验见 `evidence.json`。`preview.png` 是
实际 ARM 新稿，`comparison.png` 为同平台、同计划的新旧对照。

实际审看：格栅感减弱、宽窄断续与留白更分明；近岸不再完全死黑，右侧配山退后。
部分长皴仍像方向相近的排簇或削木纹，亮肩仍有槽带感，峰尖与局部轮廓的断笔偏多。
这是一版待审看的艺术候选，未判为大师级或艺术通过，未替换学习默认、采用为效果或
发布 WikiSkill，也未修改原图片学习记录。
