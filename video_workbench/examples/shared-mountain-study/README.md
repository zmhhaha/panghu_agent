# 共同山体：固定视角绘画研究

2026-11-23。主峰、侧峰、鞍部、坡肩和前脚先在同一 XYZ 高程网格上组织，再投影为
覆盖、深度、可见表面位置、法线和下坡方向，供 Canvas 笔触取样。主峰群与右侧远峰群
各为一张相连表面，运行中断言 `connected_components===1`，并非每座尖峰分别加深度。
这是相连表面，不是封闭实体或自动地貌重建。

`scene.html`、`scene.js` 是作者源码；`plan.json` 仍由宿主独立读取。七层十对象及二维
取景计划沿用前一研究，三维网格与固定正交相机仅保存在 `scene.js`。需要任务冻结的
绘画 API3 与对应 `tools.geometry` 字节；不能把新源码插入旧冻结任务继续执行。

默认 `ART_MODE='ink'`：可见表面上铺独立墨笔，取样到跨表面大跳跃时断笔；作者脊线
通过 `projectPoint().visible` 检查遮挡。覆盖回调使用同一投影，山脚按共同基座处理。
没有先画连续法线灰阶阴影再添加线条。把该常量改为 `'clay'` 可另建诊断源码，生成
仅供检查连接和遮挡的法线着色图；它是独立诊断条件，不参与墨稿的合成。

两张网格共10,330顶点、20,096三角形；两个投影共235,600像素。真实观测 helper 累计
预留3,798,576字节、4句柄，低于16 MiB与32句柄上限。作者额外保存位置、法线、方向、
高度、深度和alpha数组共9,659,600字节，不计入 helper 的16 MiB数值额度；原始 JS
数组、Canvas 和浏览器内存也不由该数字代表。投影与绘画初始化一次后使用静态缓存，
本例不验证逐帧三维相机或环绕观看。

真实桌面 Chrome 的墨稿、结构诊断及旧源码控制均通过重复、逆序和重载检查。相同
桌面平台的旧源码像素摘要未变，旧源码的新几何调用和句柄均为0。详见 `evidence.json`
和 [几何工具说明](../../docs/scene-shared-geometry.md)；容器及发布证据另行记录。

后续 ARM 容器验证、学习 executor 更新及累计消费见
[实施验证记录](../../docs/scene-shared-geometry-validation-20261123.md)。本目录
`preview.png`、`structure-diagnostic.png` 保留实际 ARM 墨稿与独立结构诊断，
`structure-comparison.png` 为前后版本的主峰局部对照，不是单参数消融。

画面可以读到共同山腰、前后覆盖和连接山脚，但交叉排线仍密，局部坡肩偏亮并呈阶梯感。
近岸、松树、远山和云雾继承前一研究，未声称全面美术改进。本例是结构与绘画接口
验证，尚未获得艺术验收，没有效果采用、WikiSkill 发布或原图片学习记录改写。
