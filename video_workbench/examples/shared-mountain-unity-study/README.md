# 共同山体：统一墨团与勾骨试稿

2026-11-23，接续 [笔墨疏密稿](../shared-mountain-brush-study/README.md)，旧例完整保留。
本例仍使用同一共同山体、高程、相机、原始深度/位置场及单帧计划；改变的是作者画法
及少量轮廓覆盖像素，没有新增运行时、框架字段、后端或学习默认。

`INK_DESIGN.lightDirection` 给出右上方、山后红日的作者光向假设。上一稿已有法线
点积，问题在于几道画法各自选点、长笔只判断起点，以及焦墨只从凹谷随机抽取。
本例以同一个结构墨团计划组织既有对象缓存中的三道画法：

1. **湿笔**：只在选定暗部墨团铺少量有笔腹的淡墨接触。
2. **皴擦**：共用湿笔的结构墨团与种子；长笔沿途复核光向与墨团权重，经过亮侧时提收。
3. **勾骨与焦墨**：保留少量断续脊线，从作者脊路的分叉、重复节点和局部高点中选择
   可见锚点，最多主峰4处/远峰2处落 `#111111` 重墨，不再受凹谷门槛统一排除。

这是已有对象缓存中的绘画顺序，不是新增全图灰阶着色器。光向和墨团都是作者意图，
没有求解完整自阴影、环境反射或真实光源标定；红日在山后也不能机械等同于整幅右白左黑。

原始几何与深度场源码、计划与上一稿逐字节一致。**本轮覆盖源码有变化**：复制原
alpha，在选定外轮廓小范围调整干/软边，向外仅延伸1–2像素，原内部实体覆盖保留。
相同alpha的扫描行合成一个 `Path2D` 填充。新增作者 `Uint8Array` 共235,600字节，
不计入 helper 的16 MiB额度；JS墨团对象、Path2D/native分配与浏览器RSS未由此测量。
局部干笔也在这些位置擦边，没有把整个山体淡化或在最终合成画布上挖洞。

近岸取消11个近等距竖斜单元，改连续承接树根的墨腹及不等宽横斜接触，保留灰墨通道、
少数暗核和草。松针改偏心半球状簇，后淡前浓，针向含侧伸及少量下垂，枝根依附弯干。
第一张近岸断成硬灰块、针簇偏小的试稿已淘汰，最终采用第二张，避免扩大无谓试画。

`scene.html`、`scene.js` 为作者文件，`plan.json` 由宿主独立读取，仍需要冻结 API3与
原 ink-landscape 资产。桌面 Chrome 重复、逆序、重载检查见 `native-evidence.json`；
同平台 ARM 新旧图与独立账本见 `evidence.json`。`preview.png` 是实际 ARM 新图，
`comparison.png` 是相同运行时/取景的新旧对照。

实际审看：中央主峰暗墨更成整体，近岸条码减弱，针簇方向更分散。仍有竖向削木纹、
亮阶状白肩、峰顶露纸空壳和孤立焦墨；近岸石面层次较含混，颗粒仍像砂纸。
本例为局部改善候选，`artistic_acceptance=false`；没有采用效果、发布WikiSkill、
替换学习默认或修改原图片学习记录，未验证镜头动画或长片。
