# 视频工作台：接下来做什么

更新日期：2026-10-30。

开发在独立分支 `codex/svg-video-workbench` 上进行。交付标准是接通真实 Agent、在服务器上通过登录入口使用工作台，并用真实文稿完整做完一次制作流程，达到可以上线的状态。全部完成并校验后，再整理结果请你决定是否合入主线。

目标是在你的服务器上，用现有通用 Agent 把文稿变成可预览、可修改的 SVG／HTML 画面，减少手工制作的时间和成本。

## 现在做到哪里

首版代码已经写好：可以创建项目、拆分镜头、预览画面、按批注修改、保存历史版本、选择满意版本并导出素材。

已用固定示例验证完整流程，并在 ARM 服务器构建、验证和推送了工作台及视觉执行镜像。禁网容器验证通过：非 root 和只读文件系统下可以启动、读取凭据文件、保存项目，重启后项目和会话校验数据仍保留。通用服务控制面镜像还在准备中。

工作台还没有正式上线，也还没有用真实 Agent 完成画面生成；实际画面质量、制作速度和费用需要试用确认。内部登录代理与独立会话存储的部署代码和离线测试已准备好，尚未部署。候选执行已暂停，尚未发起，本轮没有新增模型调用或残留临时资源。

本轮阶段结果与下次继续的位置见 [CHECKPOINT.md](CHECKPOINT.md)。

## 接下来按这个顺序做

### 1. 接通真实的画面生成

让现有通用 Agent 接受工作台发来的文稿和镜头说明，真正完成拆镜、SVG／HTML 画面生成和批注修改。

### 2. 在服务器上开放工作台

工作台网址已确定为 `video-service.panghuer.top`。你负责在 WebUI 后台添加域名对外开放和登录回调；我们准备内部网页、独立登录代理和数据保存，再从正式入口验证创建项目、查看画面和修改内容。登录回调地址为 `https://video-service.panghuer.top/oauth2/callback`。

### 3. 用一份真实文稿完整试做

从文稿开始，做完拆镜、生成、修改、选择版本和导出。检查中文排版与画面表达，并记录制作时间、费用和需要手工调整的地方。

### 4. 完成上线校验，再请你决定是否合并

确认实际登录和权限隔离正常，项目与历史版本能持久保存，取消任务和服务重启后能够正确恢复。真实制作流程和服务器访问都通过后，再提交完整结果与剩余限制，请你决定是否合入主线。首版代码、离线示例和本地镜像验证属于已完成的准备工作，后续真实接入与上线验证继续在当前分支完成。

## 后续方向

先把低成本的 SVG／HTML 画面制作跑通。之后再补配音、动画和 MP4 视频导出；图片生成和 ComfyUI 等成本合适时再评估。

运行和部署的具体操作见 [README.md](README.md)。
