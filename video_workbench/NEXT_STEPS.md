# 视频工作台：接下来做什么

更新日期：2026-10-29。

开发在独立分支 `codex/svg-video-workbench` 上进行。完成任务和最终校验后，整理结果交给你确认，再决定是否合入主线。

目标是在你的服务器上，用现有通用 Agent 把文稿变成可预览、可修改的 SVG／HTML 画面，减少手工制作的时间和成本。

## 现在做到哪里

首版代码已经写好：可以创建项目、拆分镜头、预览画面、按批注修改、保存历史版本、选择满意版本并导出素材。

已用固定示例验证完整流程，并在 ARM 服务器成功构建镜像。禁网容器验证通过：非 root 和只读文件系统下可以启动、读取凭据文件、保存项目，重启后项目和会话校验数据仍保留。

工作台还没有正式上线，也还没有用真实 Agent 完成画面生成；实际画面质量、制作速度和费用需要试用确认。

## 接下来按这个顺序做

### 1. 接通真实的画面生成

让现有通用 Agent 接受工作台发来的文稿和镜头说明，真正完成拆镜、SVG／HTML 画面生成和批注修改。

### 2. 在服务器上开放工作台

部署网页、接好登录和数据保存，让你可以通过浏览器进入工作台，创建项目、查看画面和修改内容。

### 3. 用一份真实文稿完整试做

从文稿开始，做完拆镜、生成、修改、选择版本和导出。检查中文排版与画面表达，并记录制作时间、费用和需要手工调整的地方。

## 后续方向

先把低成本的 SVG／HTML 画面制作跑通。之后再补配音、动画和 MP4 视频导出；图片生成和 ComfyUI 等成本合适时再评估。

运行和部署的具体操作见 [README.md](README.md)。
