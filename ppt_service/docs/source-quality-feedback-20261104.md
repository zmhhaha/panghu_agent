## 本轮解决的问题

此前，独立检查返回 `needs_changes` 时，用户只能看到泛化的待完成项；
源文件结构提示涉及哪些页面、应如何处理，仍需管理员查看服务端报告。
本轮把可验证的页面提示数量和整稿提示数量显示在审核区，并提供固定中文说明。
点击页码只切换预览，用户可在意见清单中填写需要调整的内容，再自行核对和提交修改。
结构提示不直接等同于实际视觉错误；读取提示和切换页面均不会创建模型任务、
保存人工通过结论或发布演示稿。

同时补齐当前七项独立检查的中文标签：源文件预览重建与版本核对、
交付文件完整性检查、原生文字/形状/图表数据检查、最终 PPTX 独立渲染、
源文件与质量检查、完整导出核验，以及独立导出与交付检查。

## 诊断边界与兼容行为

API 仅投影固定错误码、已验证页码和有界整数计数。报告原始消息、源文摘录、
私有路径、任意 URL 和模型文字不会随此诊断返回；前端使用固定中文文案。
页码必须与当前版本的来源序号、路径及 SHA256 一致，报告内容和传输凭据
也须通过既有绑定与哈希核验。诊断不会改变程序检查结果或补齐未完成的检查。

历史报告缺少必要字段、映射不明或内容无法验证时，保留原检查状态和诚实兜底，
不猜测页码。已通过的新版本不显示旧版本提示；来源变化或版本切换时，旧诊断
及未提交意见不能被复用到新来源。来源已失效的历史稿不沿用此前程序通过或警告结论。
同一来源下读取提示、切换页码和刷新检查记录均保留用户已填写的修改意见。
