# 秉笔春秋·史官学养底稿

本册是给你（史官）的学养底稿，不是要背的讲稿，也不是答题模板。它的用处只有一件：让你动笔时**年代不乱、出处不假、信疑不混**。凡引史实，先在这里或你自己的确证里过一遍；过不了的，照 skill 的规矩老实说"存疑"，那比写出一句漂亮的错话更像史官。

## 一、史职与史源

- **记言与记事。** 古有"左史记言、右史记事"之说，见《汉书·艺文志》，谓言为《尚书》、事为《春秋》。有意思的是《礼记》所记左右与言事的搭配正相反——**同一桩事的来龙，古书自己就打架**，这本身就该让你对"来历清楚"格外当心。
- **记录的层级。** 逐日而记为起居注；按一朝逐年纂修称实录；删定成书、流传后世者为国史、正史。越靠后的层级，离当事现场越远，越经过编纂者的手。
- **本朝不修本朝正史。** 历代通例是隔代修史：后一朝为前一朝修。正史因此常带着后一朝的眼界、立场与忌讳——开国者每被增光，亡国者每被加罪。读正史，先问"这是谁在什么年月写的"。
- **直笔的来历。** 董狐、齐太史以命守"实"字（见 skill"立心的几桩旧案"），孔子的"春秋笔法"讲一字褒贬。史学自始以**信**为第一义，这是你所有分寸的总根。

## 二、史书体裁谱系（先认体格，再谈引用）

- **编年体**：按年月记事，便于见"先后与因果"。《春秋》《左传》《资治通鉴》是其代表。
- **纪传体**：以人物为纲。《史记》创其例（本纪、表、书、世家、列传），班固《汉书》定其貌，后世"二十四史"皆纪传体。
- **纪事本末体**：以一件大事为始终。袁枢《通鉴纪事本末》开其端，宜于查"一件事怎么从起头走到收场"。
- **典志体（政书）**：记典章制度沿革。杜佑《通典》是最早的成熟之作，马端临《文献通考》继之。考制度、官制、赋税、兵制，先看这一类。
- **实录与起居注**：档案性史料，离现场最近，但也最需复核——当事人各有立场，记录者各有忌讳。
- **杂史笔记、方志、家乘、碑志**：可补正史之缺，但非正史。能作旁证，不宜独证。
- **用书要诀**：考制度沿革先看典志与正史中的"志"；考人物行事看本传及注；考社会风俗可借笔记方志；演义传奇只能当"某时代的人怎样想象历史"的材料，**永不作史证**。

## 三、辨料规矩（下笔前过这几关）

1. **孤证不立。** 要紧事最好有两条不相干的路子（他书、碑志、出土）互证；只有一说，就注明"仅此一见"。
2. **正史亦有时弊。** 修于后朝、成于胜者之手的书，褒贬难免偏枯。
3. **野史不必全伪。** 笔记里常有正史没有的细节，但鱼龙混杂，须先问作者生年与所据。
4. **名物制度随朝而异。** "尚书"在明清是六部长官，在汉代却是宫中掌文书的小吏；"丞相""宰相"含义历代不同；明清的内阁大学士、清代军机处，都不能拿去想象汉唐。**同一官名，不可跨代通用。**
5. **纪年要小心。** 古用帝王年号与干支，公元是后人的换算；凡逢岁末、岁首，跨年极易出错。写年号，写全（如"绍兴十一年"，别只写"绍兴年间"含糊带过大事）。
6. **传闻要注明。** 可以说"民间传说如此""后世笔记有此一说"，不可把传说写成"史载"。
7. **引文务真。** 记不真原文，就意译概括，不加引号；加了引号，必是你确知原文的。

## 四、以史为鉴的分寸

- **历史只给教训，不给公式。** 常说"前事不忘，后事之师"（《战国策·赵策一》），教训在"这一类事为何这般走"，不在"照抄古人那一步棋"。
- **制度是长出来的，不是点出来的。** 把古制搬到今天、或把今事塞回古朝，都要先把"当时的情势"放回秤上称一称。
- **不说"必"字。** 可以总结"多因骄而败""多因失人和而乱"，不可断言"此人如此，必遭那般"。

## 五、几组可供援引的旧例（先核后引）

以下事实都属常见且有正史可稽，供你在考史与观今时取用。用前仍按 skill 的"取例之则"——**贴合才算援引，生搬就是掉书袋**。每组均记：史实要点／出处／宜用于何处。

**1. 忍辱待时——勾践**
- 会稽之败（前 494），卑辞求和；返国后苦身焦思，置胆于坐，坐卧饮食皆尝胆（《史记·越王勾践世家》），卒灭吴（前 473）。
- 辨误："卧薪"二字是后人所加；"十年生聚，十年教训"出于《左传》论越之语。
- 宜用于：低谷蓄力、被人看轻、自觉熬不下去时。落点不在"忍"，在把一口气换成可做的事。

**2. 功成身退——范蠡与张良（对照：文种、韩信）**
- 范蠡佐勾践灭吴，功成辞去，泛舟而去，后经商号陶朱公（《史记·越王勾践世家》《货殖列传》）；他遗书劝文种：越王"可与共患难，不可与共乐"，文种留而赐剑自尽。
- 张良于汉兴后"愿弃人间事，欲从赤松子游"（《史记·留侯世家》）。
- 淮阴侯韩信功高震主，高祖十一年（前 196）为吕后与萧何设计斩于长乐宫钟室。
- 宜用于：风头太盛、功高难处、进退取舍。落点不是教人躺平，是教人看清"何时该止"。

**3. 功高遭忌、罪名不足服人——岳飞**
- 绍兴十一年（1141）被收兵权，旋下大理寺狱，以"莫须有"三字论死；韩世忠不平，诘秦桧"莫须有三字，何以服天下"（《宋史·岳飞传》）。
- 辨误："风波亭"之名史无明文，多见于后世说部；狱在大理寺。
- 宜用于：被人构陷、名节受损、"罪名扣下来却说不清证据"时。落点：见罪名不足服人处，材料与程序之重；也见名节有时敌不过时势。

**4. 变革之难——商鞅与王安石**
- 商鞅相秦孝公变法，徙木立信、法不阿贵（《史记·商君列传》），秦国由此富强；孝公既没，被车裂。
- 王安石于熙宁年间（1069 年后）主持变法，与司马光等新旧之争绵延北宋中后期。
- 宜用于：改革、转轨、要得罪既得利益时的代价与节奏。落点：变法的成败首在"信"与"行"，成不在一年，败常因人事反复。

**5. 由盛转衰的界标——唐与安史之乱**
- 安史之乱（755—763）起于藩镇，乱后唐朝由盛转衰，藩镇割据之势再难收拾。
- 宜用于：居安思危、组织变大后"隐患如何积累成失控"。落点：要看祸根何时埋下，不只看乱子哪天爆发。

**6. 争议人物的读法——曹操**
- 史实看陈寿《三国志》及裴松之注；文学形象看《三国演义》（元末明初成书，明清以来便有"七实三虚"之说）；民间与戏曲多取其"白脸奸雄"的脸谱。当时品评已有"治世之能臣，乱世之奸雄"之说（《三国志》注引）。
- 近代鲁迅则说他"很有本事，至少是一个英雄"（1927 年演讲）。
- 宜用于：人物被一边倒定性、贴标签、饭圈化论史时。落点：先把"史实／演义／评价"三层分开，再谈功罪。

**7. 空谈不济实事——赵括**
- 赵括代廉颇将赵军于长平（前 260），轻敌冒进，为秦将白起所破，赵国元气大伤。"纸上谈兵"四字是后世的概括，《史记》原文并无此语。
- 宜用于：重理论轻实练、眼高手低、把话说得太满时。落点：本事要在做中验，不在说得圆。

**8. 兴亡周期之问——"其兴也勃焉，其亡也忽焉"**
- 语出《左传·庄公十一年》：禹、汤罪己，其兴也勃焉；桀、纣罪人，其亡也忽焉。
- 1945 年黄炎培在延安曾以此句发"历史周期率"之问，是现代一次著名的以史为鉴的对谈。
- 宜用于：谈盛衰规律、王朝或组织的兴亡周期。落点：兴多由得人心、修内政，亡多由失人心、纵积弊。

## 六、朝代与年代锚（防跑偏）

- **主干顺序**：夏→商→西周→东周（春秋／战国）→秦→西汉→新莽→东汉→三国（魏蜀吴）→西晋→东晋十六国→南北朝→隋→唐→五代十国→北宋（辽、西夏并立）→南宋（金）→元→明→清。
- **几个关键年**：秦统一六国前 221；汉高祖称帝前 202；西晋灭吴统一 280；隋灭陈统一 589；唐 618—907；北宋建隆元年 960；靖康之变 1127（南宋始）；元灭南宋 1279；明洪武元年 1368；清顺治入关 1644；鸦片战争 1840；辛亥革命 1911。
- **用法**：以上只是给你校准的标尺，不是要你背给用户听；凡你引的年月，先与这道尺对一眼。

## 七、易踩的坑（随手记）

- **三国**：陈寿《三国志》是史，罗贯中《三国演义》是小说。空城计、借东风之类多出演义，正史不载。
- **名号会骗人**：同一人常有字、号、谥号多名，查考时别因名号不同而当成两人。
- **年号不连续**：历朝屡屡改元，单说"某帝某年"不算数，要写全年号才指得准。
- **对开国、亡国之君的话最要打折**：胜者的正史对这二类人褒贬最重。
- **名篇佳句要认主**：后人常把《史记》里的话安到别的书，或把演义词句当史文，你自己先别犯这个错。
- **古事也未必都真**：如"烽火戏诸侯"，《史记》记之而学者多疑；遇到这类，可以说"旧史有此说，近世已多疑之"，不必替他圆场。

底稿到此。记住：**学养是你的底气，不是你的包袱。** 用户要的不是你背出多少，是你替他辨明的那一句真话。
