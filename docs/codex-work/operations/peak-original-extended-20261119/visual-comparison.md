# 原版与修复版实际采样画面对照

日期：2026-11-19。仅直接观看以下两张各含 8 帧的 montage；没有阅读源码判断画质，没有调用外部模型或业务操作，没有播放完整视频或试听音频。

- 原版：`D:/codex-work/archives/video-service/20261119/peak-original-local-gpu/montage.jpg`
- 修复版：`D:/codex-work/archives/video-service/20261119/peak-render-repair/0442d32a6bea4796a211aa21a266376b-montage.jpg`

## 判断

就这次可见画面而言，原版的云海厚度、雾绕山脚和前后遮挡更好，我会优先保留原版作为这些效果的视觉方向。此前修复版虽然完成导出，但不能因此认为它的画面与原版相当。原版并非每一项都更好，也仍有值得改的构图和峰体问题。

| 观察项 | 原版可见结果 | 修复版可见结果 |
| --- | --- | --- |
| 云层体积与遮挡 | 明暗云团重叠，有较大的高低起伏；近处较虚、远处细密，山脚被雾柔和地吞没，空间较连贯。 | 大量形状近似的圆团铺在同一平面；团块之间的平坦区明显，山脚与云层的接触偏硬，厚度较弱。 |
| 条带与重复感 | 仍能见到横向明暗带和前景偏糊的大片云团，但整体更像连续云海。 | 相似云团的重复较醒目；部分云团像一层浮在底面上的棉球，容易看出铺排感。 |
| 峰形与材质 | 峰体高耸、剪影明确，与暖云形成强反差；许多近峰内部接近整块黑色，可读的山面层次不足。 | 峰体侧面、折角和裂纹更可读；部分白色竖纹和硬折面也比较突兀，容易显得像多边形岩块。 |
| 画面主次 | 大山与亮云的强反差有冲击力；起始部分山顶已超出画面，中段近峰占比很大，局部只剩黑色遮挡。 | 起始山群更完整地留在画内，主体关系容易辨认；云海表现减弱后，整体纵深与气势相应变弱。 |
| 采样镜头状态 | 可见从山群到近峰遮挡、再到开阔云海的状态变化；后段主要是云海与很小的远峰，主体偏弱。 | 也能见到相似的近峰经过与后段开阔状态；同样有近峰遮挡过满、后段视觉中心不足的问题。 |

两版取景和山体占比存在差异，不能把全部观感差异都归因于材质。这里没有给出客观分数，也没有把这些离散状态当作镜头速度、转场流畅、云的连续运动、音画或完整视频验收。

## 可以直接回答用户

“看过实际画面对照后，原版的云海确实更好：更厚、更有前后层次，雾与山脚的遮挡也更自然。现在修复版虽然能稳定导出，但把这些质感削弱了。我会保留原版方向，继续改善山体过黑、近景遮挡过满和后段主体偏弱的问题。这个判断来自两版的实际采样画面，还不代表已经验收完整运动和声音。”
