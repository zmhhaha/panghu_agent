# r2 最终独立视觉评审

2026-11-19。直接查看本轮r2 `still.png`、`reference-and-result.jpg`、`baseline-and-result.jpg`、`shader-on-off.jpg`，并与已查看的r1、528基线和清晰参考比较。只评价实际单帧；本轮两次艺术输出预算已用完，不请求继续渲染、不给新增分数、不自动采用或发布。

## 结论

**r2相对r1减少硬边剪纸感，前景也转向较克制的中性墨色；但新增细线趋向均匀刷丝/毛发，岩体的自然皴擦和浓淡干湿仍未成立。整体未达到参考，不能确认整体优于528基线。Shader同源开关仍缺少足够清楚的视觉收益证据。** 与统筹初步判断基本一致。

## 相比r1可见的变化

- 主峰大色块之间的接边软化，岩体不再主要由孤立的硬多边形组成。连片暗部保留了一定重量，没有退回昨天通顶长亮槽。
- 前景由偏绿灰色块转为较中性的黑灰，硬质拼贴减少，方向性的擦痕更明显。
- 树干、枝团和整体空间关系大体沿用r1，不将这些继承内容写成r2新增改善。

## 仍影响目标的主要问题

| 范围 | 实际可见问题 | 与参考的差距 |
| --- | --- | --- |
| 主岩体 | 暗部和亮部仍呈几块大而接近填色的区域，细丝附着在其表面；中央群峰整体仍偏单个三角锥团，局部岩面转折不足 | 参考由连片浓墨、少量强骨脊、局部短皴和断续留白共同塑形，不依靠整面覆盖的细丝 |
| 笔触 | 细线数量增加，但长度、粗细和走向过于接近；主峰和前景都呈梳理过的纤维/毛发感 | 参考笔墨尺度不均，有短擦、粗骨、沉墨与枯白咬合；不是越多细线越像毛笔 |
| 云根 | 山脚细线延伸入雾区，许多在相近水平结束，局部形成薄挂帘/铅笔划线感 | 参考根部浓墨向灰墨和纸白的过渡更不均，留白吞没部分笔势，虚实边界更自然 |
| 前景 | 中性墨色改善，但整块斜坡仍被同方向细纹覆盖，内部岩面分组较少 | 参考前景有深浅斜面相互压叠，擦痕粗细和间断变化更大，仍保留大块实墨 |
| 同源Shader开关 | 当前整体和两类局部对照非常接近，能感到少量边缘/墨色变化，但不足以明确证明更自然的湿化或沉积 | 不能把分区纹理、非零差异或硬件执行成功写成艺术收益。0/1比较不等于“所有Shader与Canvas组合”比较 |

## 对528及昨天r4的取舍

r2的暗部岩体比昨天r4连贯，前景封口没有复现，松树也不再是规则镜像层。这些是相对r4的明确修复。相对528，r2大形更连贯、远山没有明显矩形接缝；528仍有较多不均匀的墨迹和粗粝断裂，虽然本身有贴片和硬切面问题。两者各有缺陷，不能因r2技术更复杂或修复了某项就认定整体已超过528。

## 本轮应该保留的认识

分开造形、湿墨、干笔、深度和云雾的数据有助于针对不同区域调节；本轮可见产物仍未证明这种分工已带来足够好的水墨效果。当前瓶颈是笔触与岩面的组织、墨量的局部层次和虚实边界。继续增加细丝、统一柔化或扩大扰动都可能重复本轮问题。

本轮按既定两次输出停止。保留r1/r2及参考/旧版/同源消融，不替换较好旧版。连续运动、声音、迁移、用户艺术认可和生产后端准入均不在此静态评审的证据范围。
