# r1 独立视觉评审

2026-11-19。实际查看 `r1/still.png`、`reference-and-result.jpg`、`shader-on-off.jpg`，以及wet/dry/depth/cloud四张语义图。此前已看清晰参考、528基线与昨天r3/r4。这里只评价可见单帧，不审查运行时合同，不宣称连续运动、音效或用户认可。

## 结论

**r1摆脱了昨天贯通浅槽和纵向帘幕，形成较连贯的暗部岩体；但整体转为硬边低多边形/剪纸语言，尚未达到参考的水墨质感。不能判定整体优于528，也不能凭本次shader开关图判定材质已显著改善。** 这一判断与统筹初看一致。

## 对照五项标准

| 标准 | 实际所见 | 判断 |
| --- | --- | --- |
| 岩体与体积 | 暗部连片，主峰和左右肩部有不等高/遮挡；未再用等宽长亮槽贯穿整座。中央仍偏单一三角锥群，大小岩面被硬色块分开 | 大结构较r4前进；尚未达到自然山石与笔墨融合 |
| 皴擦服从岩面 | 有短的斜向断笔，但大岩面内部色值近乎恒定，明暗交界是分段多边形。笔触微观浓淡、枯湿和飞白很少，浅面像剪下再贴上的片 | 核心未通过，需从墨量过渡重做 |
| 深度与留白 | 前景深、远景浅、主峰根部入雾成立；大片背景留白清楚。雾以浅而水平的渐隐处理为主，虚实变化有限，主峰黑与纸白之间层次不足 | 基本空间成立，水墨气息不足 |
| 前景与树木 | 未见画内垂直封口，树干/枝组比r4不对称。前景是深绿灰与浅灰的硬块拼合，像几何岩壁；枝端较刺、针叶方向相近 | 结构有修复，材质与树的笔意尚不成立 |
| Shader可指出收益 | 0/1的整体、山体和前景对照在当前展示倍率下非常接近；没有看到足够清楚的选择性湿边/沉积收益。四张语义图确实显示不同区域和云带形状，但图像本身不证明消费或质量 | 可继续做局部材质对照，不能以非零像素差或遮罩存在判改善 |

## 给唯一一次r2的优先建议

1. 保留连片浓墨作底，但在同一岩面内部引入随笔路/压力变化的墨量、断续露纸与窄的擦痕，跨越硬切边时让部分笔势连续。需要黑→灰→枯白的局部过渡，而非增加更多小多边形。
2. 岩面亮部仍应断开/转折，允许少量长骨脊；不要回到全山等距纵向拉丝。主体暗部不能全部变模糊，否则会丢掉刚建立的重量。
3. 前景色相收回克制的中性浓墨，大色块边缘通过有方向的擦痕和墨边松紧解开；增加随机颜色颗粒不等于水墨。
4. Shader只在湿区增加可辨认的渗化/边缘墨量变化，同时保护干笔和树枝。能用同像素局部0/1指明实际收益后再作判断，不要求扩大全局扰动。

本轮总共最多两次艺术输出；上述是定向建议，不要求额外渲染、不请求加轮、不自动采用或发布技能。
