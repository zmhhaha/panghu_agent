## 修复行为

- 来源索引给出精确 `paper_id`、可用访问范围和七字段证据模板。即使引用上传资料，也在 `paper_id` 中填材料 UUID；不能另造 `material_id` 字段，所有证据字段都必须是非空字符串。只取得元数据的来源不能声称已读取摘要。个别来源缺失时保留其他可用来源，并列出缺口。原结构、来源和访问校验继续生效。
- 失败任务显示固定安全原因、失败子步骤、重试建议、业务/Agent 任务 ID，并可下载脱敏诊断。时间来自实际事件；刷新页面不构成任务进展。成果保存失败与输出校验失败分开记录，保存未确认时不重新提交模型任务。
- 保存筛选后保留旧版证据和大纲，标记“基于上一版筛选，待更新”。历史可查看、复制和下载。新快照完成校验后才替换当前快照；旧范围不能直接确认写作。旧版本已经隐藏的入口通过历史投影恢复，不批量重写数据库。
- 证据页提供人工整理，仍检查实际来源与访问范围。报告页可导入 Markdown 或人工编辑，创建明确标记为“用户导入／人工编辑”的候选；单独审阅来源和证据限制后再采用、私有定稿。不会伪造前置执行成功或机器引用链。无机器引用链的稿件使用人工修改入口，模型章节修订明确受限。
- 检索默认筛选增加年份、主题和明显测试题名说明，保留原始观测及用户覆盖入口；不通过 DOI 前缀判断真假。开放年份、中文主题和跨语言检索保守处理；查询、provider、结果数和预算缺口可查看。
- 新采集保留提供方返回的完整作者及完整性、数量，分别记录首版、版本更新、期刊/在线/印刷日期和访问时间。旧数据不伪造补全；未知日期不从预印本年份推断期刊年份。需要新 control/Pi 镜像后新检索才生效。
- 文件解析显示“文件已读取”，与内部来源的元数据／摘要／全文分开。可明确声明资料包内来源及摘录位置，也可把恢复稿标为稿件而排除独立文献计数。声明不是自动核验，不自动建立包内文献的机器引用链；重复摘录和同一来源按已声明标识去重。
