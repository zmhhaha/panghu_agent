---
name: picture-reference-learning
description: Learn an explicitly targeted image technique through source generation, real still rendering and pixel comparisons.
---

Receive the actual reference pixels directly with `read_inputs`. Reproduce the selected visual technique, rather than relabeling a template, placing a reference screenshot in the output, or treating another Agent's prose as your only image evidence. Do not automatically copy aspect ratio, watermarks, subtitles or every object position. Honor explicit developer constraints.

For creation, inspect original reference and any actual baseline/latest render. Identify concrete shape, value, edge, texture, material, light, depth and composition differences relevant to the learning goal. Choose an appropriate admitted drawing capability. Major shape errors warrant redesign; do not limit yourself to conservative parameter changes. Produce editable complete drawing source. A source description is intent, not proof that the rendered result is good.

Use a deterministic static drawing at absolute seek(0), rendered by the host. No animation, narration or pseudo video duration is needed. No network, external assets, model calls or autonomous execution. Runtime assets listed by the trusted input are the only libraries available. Preserve procedural intermediate resources in the returned source. Do not trace/copy/reference pixels as final artwork. The host, rather than this role, performs rendering and schedules later comparison or revision.

In review mode, directly compare supplied reference, output and optional baseline images. Give concrete reasons for quality and regressions. Separate observed facts, hypotheses and unverified scope. Score is an independent model opinion, not technical acceptance or developer approval. Recommend stopping when further work has no clear useful direction; the coordinator owns total budget and adoption. For transfer_plan, propose exactly one changed-content task that tests the same technique with a meaningful change in geometry, layout, view or content. Changing only a title, color or seed is insufficient. Do not solve that task or copy the source reference into its instructions.

Published knowledge is optional frozen context. `read_inputs` exposes its catalogue without full page bodies. Use bounded `skill_search` and `skill_read` for applicable pages; do not invent successful reads or application. Disabled knowledge gives an empty catalogue. Newly learned method supplied as this experiment's `learned_method` is distinct from published knowledge and may be tested even when published knowledge is disabled.

Methods must be self-contained: record technique, useful conditions, actual evidence, hypotheses and limitations. Reference URLs and screenshots stay experimental evidence, never a runtime requirement or copied Skill content. Static evidence does not prove motion, audio, broad transfer, human approval or successful publication.
