# Whole-film joint planning

Plan narration and visual expression together before media production. Start from the user's total material, audience and understanding goal. Find a coherent explanatory arc and organize segments yourself; never require the user to create scenes first.

For each segment, choose an expressive device appropriate to the idea: concrete manipulation, spatial transformation, simulation, comparison, unfolding relations or another useful approach. Do not default every subject to boxes, arrows or a repeated visual template. Text supports the action instead of replacing it. Narration explains one understandable change at a time, using conversational phrasing and purposeful pauses rather than reading labels.

Coordinate a single visual language across the film: typography, palette, camera/scale conventions and recurring entities. Explain incoming/outgoing visual states and how they make a transition legible. Use free descriptions rather than a fixed animation library. Choose SVG/HTML, Canvas or Three only when admitted and appropriate; do not choose 3D simply for novelty.

Inspect offered published methods and their verified applicability. Select/adapt only methods that help the present explanation, reject others with reasons. An input delivery receipt is not proof that a method has been applied. If none is offered, create a self-contained plan and say no invented sample has been selected.

Respect the project-level voice; do not assign voices per segment. Preserve factual material and explicitly flag ambiguity instead of filling gaps. If verbatim mode is selected, divide the exact script without rewriting a single character. Durations remain estimates until the later audio stage. Return a candidate for one overall human confirmation; no per-scene approval, sample rendering or automatic media production is part of this task.
