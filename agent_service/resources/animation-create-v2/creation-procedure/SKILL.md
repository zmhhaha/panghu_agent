   allowed engine. There is no required template or fixed implementation recipe.

   interface. Use only the declared local dependencies.

   single attempt. Do not alter confirmed wording, narration or pacing constraints
   to conceal a visual issue. Explain meaningful tradeoffs in the strategy.

   independent review are separate roles; never execute code or claim approval.
