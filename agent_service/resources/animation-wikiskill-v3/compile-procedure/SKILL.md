---
name: compile-animation-wikiskill
description: Internalize a complete frozen three-library evidence snapshot into a compact, self-contained hierarchy of authoring Skills.
---

Produce a useful current library within one bounded compilation. All original
records remain supplied, immutable and individually hash-bound. A large source
history is evidence to select from, not a requirement to reread every repeated
source program or execution prompt in full.

1. Survey the entire snapshot with `read_compilation_input`, mode `survey`,
   offset 0, limit 128, then every returned next_offset until null. This fixed
   directory contains only indices, original file hashes, short title labels,
   statuses and explicit verification flags. It omits all substantive prose,
   programs, reviews, feedback and acceptance context. Directory coverage is
   not source reading. Index N addresses `records/NNNNNN.json` (six digits).
2. Group evidence by expressive problem and provenance, not one Skill per run.
   Use mode `file` or `batch` for selected exact originals where omitted code,
   detailed review or guidance is needed to support a concrete lesson. Follow
   continuation offsets as necessary. Avoid wasting the deadline on duplicate
   base source, prior knowledge snapshots and repeated prompts already present
   as dedicated source records. Prioritize concrete methods, their recorded
   reviews, explicit feedback and withdrawals; read the actual originals before
   deriving specific lessons. A record indexed but not deeply read can be
   excluded with that exact reason; never invent its content.
3. Author a compact decision root and a few focused children. Teach principles,
   applicability, technique, tradeoffs, common failure patterns and checks. Keep
   useful alternate routes and static-only/partial/failed transfer limits. Render
   success is not visual approval; sampled frames are not continuous viewing;
   no supplied audio means no new listening. Do not promote scores or planned
   techniques into verified capabilities. Preserve withdrawn feedback honestly.
4. Internalize methods. Do not copy reference-video content, external URLs,
   complete programs, private logs or long historical IDs into Skill prose.
   The Skills must remain useful without the original reference website. New
   content still requires Agent judgment and real rendering; these are creative
   methods, not mandatory compositions or fixed drawing templates.
5. Account for every record once or more in the index, or once in exclusions.
   Use compact half-open record-index ranges from the survey. This reduces only
   transport repetition: the trusted collector expands every range to the exact
   original IDs and enforces the existing complete-snapshot coverage checks.
   Exclusion ranges may group records sharing a truthful reason. Do not claim
   that this grouping means all original text was read.
6. Reserve sufficient output budget. Prefer a small useful library over dozens
   of redundant packages. Check local links, hierarchy, applicability, evidence
   ranges and limitations, then write the complete JSON once to output.json.
   Publication remains a separate host action; do not request more models or
   start media work inside this task.
