# 佛法无边·学养底稿

本册给你当"讲佛法不出错"的坐标：名相要准，出处要真。佛经浩如烟海，禅门公案又多靠口耳灯录相传，**凡是你记不真出处的，就说"相传""禅门有此一桩公案"或只讲大意，不要谎称"经里说的"**。回答以慈悲为本，不必堆术语。

## 一、教理骨架（常用名相要准）

- **四圣谛**：苦、集、灭、道。苦谛说苦，集谛说苦的来由（贪爱、无明），灭谛说苦可以息灭，道谛说息苦的路。
- **三法印**：诸行无常、诸法无我、涅槃寂静——判别是否佛法的根本标尺。（有的说法加"有漏皆苦"作四法印。）
- **五蕴**：色、受、想、行、识——身心由这五类积聚而成，"蕴"即积聚。
- **十二因缘**：无明、行、识、名色、六入、触、受、爱、取、有、生、老死，环环相扣。
- **八正道**：正见、正思惟、正语、正业、正命、正精进、正念、正定。
- **六度（大乘）**：布施、持戒、忍辱、精进、禅定、般若。
- **四无量心**：慈、悲、喜、舍——愿众生得乐、愿众生离苦、随喜众生之乐、平等无著。
- **缘起与性空**：一切法皆因缘和合而有（缘起），故无恒常不变的自性（性空）。"空"不是"没有"，是"不实有、不住着"。破的是"我执""法执"。
- **几个词**：涅槃是贪嗔痴永断的寂灭，不是断灭；般若＝照见实相的智慧；菩提＝觉悟；菩萨＝觉有情，自度度他。
- **八苦**（常见的说法）：生、老、病、死、爱别离、怨憎会、求不得、五蕴炽盛。

## 二、佛传与佛教东传（讲常识，别钉死年号）

- 释迦牟尼，姓乔达摩，名悉达多，迦毗罗卫国（今尼泊尔境内）净饭王之子。出家、六年苦行、菩提树下成道（今印度菩提伽耶一带）、鹿野苑初转法轮度五比丘、拘尸那罗入灭。**生卒年代古今说法不一**，学界多推在公元前五世纪前后——回答时不必较真到某一年。
- 佛教约在汉代传入汉地，"明帝梦金人、白马驮经"是后起的传说，只能当文化掌故讲，别当信史。
- 汉传佛教主要宗派：禅、净、律、天台、华严、唯识（法相）、三论、密等。说"哪一宗怎么讲"之前，先想清楚对象。

## 三、常见经典与引用分寸

- **《心经》**：玄奘译本流传最广。"照见五蕴皆空，度一切苦厄""色不异空，空不异色"。空宗要典，极短。
- **《金刚经》**："一切有为法，如梦幻泡影，如露亦如电，应作如是观。""应无所住而生其心"一句亦出自此经（禅门相传六祖闻此句而有省）。说"空"常引它。
- **《法华经》**："衣里明珠""穷子喻""火宅三车"等喻都出于此，讲"会三归一"，人人本有佛性。
- **《华严经》**："一即一切，一切即一"式的圆融观（华严"法界缘起"），讲事事无碍。
- **《六祖坛经》**：六祖慧能的说法记录，是唯一被称作"经"的汉地撰述（实为语录）。"不是风动，不是幡动，仁者心动"出此。
- **《维摩诘经》《楞严经》**等：前者文学性极强（维摩示疾、天女散花），后者在汉地极受重视，但历代都有"是否印度原典"的争论——作信仰与文化讲述可不必卷入考证。
- **拈花一笑的分寸**：迦叶破颜微笑的故事常见于禅门灯录；它所托的《大梵天王问佛决疑经》学界多认为晚出假托。引此公案时说"禅门相传"，不要一口咬定"某部佛经如此记载"。

## 四、灯录与公案（出处这样说才稳）

公案多数不在一部"佛经"里，而在**灯录与语录**里流传：《景德传灯录》（北宋道原）、《五灯会元》（南宋普济汇编）、《碧岩录》（宋圆悟克勤）等。说公案就用"相传／禅门有此一桩公案／灯录里记着"这类措辞。

**两处与 skill 公案库对校，答时以本册为准：**

- **野鸭子（马祖与百丈）**：是**马祖道一**问、弟子**百丈怀海**答，别把主客写反。大意：百丈随马祖行次，见野鸭子飞过。马祖问："是什么？"百丈答："野鸭子。"马祖问："什么处去也？"答："飞过去也。"马祖遂扭百丈鼻子，百丈负痛失声，马祖说："又道飞过去也！"百丈于此有省。（灯录所载，细节各本略异。）
- **云门的两则别混**："云门胡饼"是云门文偃答"如何是超佛越祖之谈"等问的著名答语（"糊饼/胡饼"）；答"如何是佛"而说"干屎橛"的，也传为云门。**别把"胡饼"与"干屎橛"揉进同一则公案。**

## 五、意象与用词的边界

- "千江有水千江月，万里无云万里天"是宋以来流传的禅诗、格言，**不是某一部佛经的原句**，引时不必说"经云"。
- "轮回""超度""因果"这类词在民间佛道通用，但落到具体教理各有准头；不要把"因果/业"讲成吓唬人的工具（呼应 skill 禁忌）。
- 慈悲是"看见你在苦里"的暖意，不是要求你句句讲空理；名相点到为止，让话有人味。
